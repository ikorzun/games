# 08. Грамматика кадра: раскадровка сцен, сеты и монтажёр в рантайме

Решение владельца (2026-10-11): персонажи вписываются в окружение сцены, и каждая сцена показывается
не одной постановкой, а **покрытием** — общий, средний, крупный план, «восьмёрка», детали и неожиданные
ракурсы, как в кино. Цель — передавать динамику разговора, тревожность и напряжение через крупность,
пространство кадра и ракурс. Основа — исследование `../research/04-cinematic-emotion-grammar.md`;
правила промптов — `../production/prompts/style-bible.md` §1a. Этот документ — решения проекта.

## 1. Словарь

| Термин | `kind` | Что это | Когда |
|---|---|---|---|
| Общий / установочный | `wide` | всё помещение, люди малы | начало сцены, пауза, рассказчик, «система больше человека» |
| Средний | `medium` | по пояс, двое-трое | спокойный разговор, выборы игрока |
| Через плечо | `ots` | 50 мм, спина одного — лицо другого | диалог двоих: «восьмёрка» (пара `from`/`focus`) |
| Крупный | `close` | лицо и плечи, 85 мм | напряжение, признание, решение; `expression` обязателен |
| Реакция | `reaction` | крупный/средний план **слушающего** | длинная реплика собеседника; реакция важнее говорящего |
| Деталь | `insert` | руки, документ, сигарета, телефон, ключи | улика, пауза, смена темы |
| Ракурс | `angle` | нижний (с пола/стола), верхний (со шкафа), через дверной проём, отражение, передний план | перебивка; давление, наблюдение, угроза |

Ракурс (`angle`): `eye` (по умолчанию), `low`, `high`, `doorway`, `reflection`, `foreground`.

## 2. Эмоциональная грамматика (по исследованию `../research/04-cinematic-emotion-grammar.md`)

Принципы, которые монтажёр и шот-лист считают правилами (источники и оговорки — в исследовании, §1 и §3):

1. **Крупность — это дистанция.** Чем крупнее лицо, тем быстрее и сильнее читается эмоция; общий план делает
   человека малым в пространстве (изоляция, «система больше человека»). Нарастание напряжения = сужение кадров:
   общий → средний → через плечо → крупный → деталь.
2. **Реакция важнее реплики.** Длинная реплика идёт на лице слушающего; ответ — на лице говорящего.
3. **Ракурсы работают парами.** Нижний на того, кто давит, верхний на того, кого давят; уровень глаз — доверие
   и нейтральность. Крен кадра — только с мотивом и только в pursuit/confrontation.
4. **Скрытое тревожит.** Кадр из коридора через дверной проём, плечо или предмет на переднем плане, силуэт без
   лица, отражение в стекле; нехватка «воздуха» перед взглядом (short-siding) — тревога, избыток воздуха над
   головой — уязвимость.
5. **Объектив.** Длиннофокусный — наблюдатель, слежка, изоляция; широкоугольный — пространство и зазор между
   людьми; у лица — только 85 мм.
6. **Свет мотивирован.** Жёсткий малый источник (голая лампа, настольная лампа) — давление; мягкое окно —
   открытость и горе; верхний свет прячет глаза; контровой — анонимность. Люминесцентный кабинетный свет —
   «клиническая» тревога.
7. **Ритм.** Частые короткие кадры — напряжение; длинный пустой общий план — пауза и тяжесть. В статике VN
   движение камеры заменяют: смена крупности (наезд = переход на более крупный кадр), удержание кадра,
   реплика поверх реакции, вставка-деталь.
8. **Насилие — за кадром:** пауза на пустом общем плане → деталь → реакция.

Схемы ситуаций эпизода (крупности — `kind` из §1; подробные обоснования и ключевые слова — таблица §2 исследования):

| Ситуация (сцены ep01) | Последовательность кадров | Ракурс, объектив, свет |
|---|---|---|
| Допрос, давление (s20, s38–s41) | `wide` → `ots` → `ots` ближе → `close` допрашиваемого → `insert` руки → `reaction` | уровень глаз; «низко на давящего / выше на подавленного»; голая лампа сверху, жёсткий боковой свет |
| Признание, решение (s40, s41, s42) | `close` лица → удержание → отход на `medium`/`wide` как выдох | 85 мм, чистый фон, мягкое окно или Rembrandt |
| Лгущий свидетель (s16–s16c, s29) | `medium` свидетеля → `reaction` следователя → `insert` руки → возврат | слегка сбоку, частично закрыт плечом, отражение в стекле, ровный дневной свет |
| Страх (s35–s36b) | долгий `wide` ожидания → резкая `insert` → `reaction` | `high` на испуганного, фигура в нижнем углу, низкий ключ, силуэт в проёме |
| Горе родственника (s14, s22) | `wide` издали → `medium` с долгим удержанием | уровень глаз, малая глубина резкости, пасмурное окно |
| Давление начальника (s19) | `wide` с начальником за столом → `ots` от подчинённого → `close` | `low` на начальника, папки на переднем плане, окно за спиной — глаза в тени |
| Слежка, засада (s28, s34) | статичный `wide` ↔ `insert` деталей (часы, рука, стекло) | длинный фокус, через стекло машины, фонарь и фары, низкий ключ |
| Место преступления, пустая квартира (s03, s13, s37) | `wide` пустого интерьера → `insert` печать/замок → `reaction` → пауза | от порога, проём как рамка, плоский дневной свет |
| Телефонный звонок (s16b, s26–s27) | `close` говорящего → `insert` трубка/диск → `reaction` слушающего | уровень глаз, собеседник не показан, бытовая лампа |
| Ночной обыск (s37) | `insert` → `wide` → `insert`, паузы | один источник (фонарь, лампа), низкий ключ, `foreground` хлам |
| Суд (s43–s44) | `wide` зала → одиночные `medium` → `insert` руки, решётка | слегка сверху, симметрия, люминесцентный свет, десатурация |
| Кабинет, спокойный разговор (s11–s12, s23, s26) | `wide` → `medium` → `ots`/`ots` → `reaction` → `medium` | уровень глаз, 40–50 мм, окно + настольная лампа |

## 3. Модель данных

### 3.1 Сеты и кадры (`assets.shots`)

Кадры генерируются и хранятся по **сетам** — локация × освещение × состав, — а не по сценам: крупный план
Громова за столом один и тот же во всех сценах кабинета. Сет = `bg` + `lighting` (`day`, `evening`,
`night`, `lamp`) + состав, который в нём встречается.

```json
"shots": [
  { "id": "sh_office_day_wide_3",
    "set": "office_day", "bg": "bg_office_prosecutor",
    "kind": "wide", "angle": "eye",
    "cast": [ { "who": "expert", "expression": "neutral", "mask": "assets/ep01/shots/office_day/wide_3.expert.webp" },
              { "who": "sledak", "expression": "neutral" },
              { "who": "oper", "expression": "grin" } ],
    "focus": null,
    "file": "assets/ep01/shots/office_day/wide_3.webp" },
  { "id": "sh_office_day_ots_sledak_expert",
    "set": "office_day", "bg": "bg_office_prosecutor",
    "kind": "ots", "angle": "eye",
    "cast": [ { "who": "expert", "expression": "neutral" }, { "who": "sledak" } ],
    "from": "sledak", "focus": "expert",
    "file": "assets/ep01/shots/office_day/ots_sledak_expert.webp" },
  { "id": "sh_office_day_close_expert_focused",
    "set": "office_day", "bg": "bg_office_prosecutor",
    "kind": "close", "angle": "eye",
    "cast": [ { "who": "expert", "expression": "focused" } ],
    "focus": "expert",
    "file": "assets/ep01/shots/office_day/close_expert_focused.webp" }
]
```

- `cast[].mask` — маска человека (белый на чёрном, 480×270) для подсветки того, на ком внимание (опционально; без
  маски подсветки нет). Решение владельца 2026-10-13: в фокусе говорящий, а в мыслях героя и на выборе — герой
  («все ждут его решения»); рассказчик — никто. Рендерер PixiJS приглушает окружение примерно на 30 % и кладёт мягкий
  контровой свет на край силуэта сверху (`runtime/src/stage/focus_filter.ts`); смена говорящего — переход 450 мс,
  после склейки — сразу. DOM-рендерер подсветки не делает.
- `memory` — тот же кадр в графике «Воспоминания» (решение владельца 2026-10-13; `03-visual-language.md` §9b):
  `{ "file": "…/hod_memory/<set>/<name>.webp", "square": "…/<name>.square.webp", "masks": { "<who>": "…" },
  "square_masks": { "<who>": "…" } }`. `file` — 1920×1080, `square` — 1200×1200 для вертикального экрана; маски
  свои: силуэты в рисунке не совпадают с реалистичными (`tools/hod/masks.py --memory`). Нет файла — играет
  реалистичный кадр. Генерация — `tools/hod/memory.py`.
- `focus` — о ком кадр (говорящий для `close`/`ots`, слушающий для `reaction`); `from` — через чьё плечо.
- Файлы: `assets/<ep>/shots/<set>/<name>.webp`, 1920×1080; генерация — по `style-bible.md` §1a с
  референсами фона и спрайтов; маски — `tools/hod/masks.py` (Apple Vision локально: без кредитов и без отправки кадров наружу; кто есть кто —
  по порядку слева направо).

### 3.2 Сцена и шаги

- Сцена: `"coverage": "office_day"` — сет, из которого монтажёр берёт кадры. Без `coverage` сцена показывается
  как сейчас (фон + спрайты).
- Шаг `say`/`narrate`: необязательное `"beat": "calm" | "tense" | "climax"` — напряжение момента для
  монтажёра (по умолчанию `calm`; `tense`, если выражение говорящего из «напряжённых»: tense, angry, scared,
  cornered, nervous, worried, firm, cold).
- Шаг `say`/`narrate`/`show`: необязательное `"shot": "<id>"` — явный кадр сценариста (монтажёр подчиняется).
- Схема и линтер: `shots[].bg` объявлен; `cast[].who` в `cast`, выражения — из набора персонажа; `file`
  существует (в режиме `--require-assets`); `coverage` ссылается на существующий сет; `shot` — на кадр того же
  сета. Спрайты остаются обязательным запасным вариантом.

## 4. Монтажёр (runtime, детерминированный)

Выбор кадра — чистая функция от (сет, предыдущие кадры сцены, шаг, состояние). Детерминизм — чтобы загрузка
сейва и откат показывали тот же кадр: зерно = `scene_id + step_index`.

1. **Вход в сцену** → `wide` сета с максимальным совпадением состава на входе: кто появился по `show` до первой
   реплики персонажа, и сам первый говорящий; пришедшие позже (дверь открылась после реплики) не считаются.
   В кадре не может быть того, кого нет на сцене, — такой `wide` не берётся. Нет подходящего — спрайты.
   Общий план входа держится и на первой реплике сцены, если говорящий в нём есть: иначе он виден только на время
   перехода и мелькает перед первым крупным планом (замечание владельца 2026-10-12, s02).
2. **Реплика X** (`say`):
   - если текущий кадр уже про X (`focus == X`) и он держится меньше трёх реплик → не резать, пока напряжение
     не растёт: `calm` держит и `ots`, и крупный план; `tense` на `ots` режет в крупный план, а на крупном
     плане меняет только выражение (если такой кадр есть); `climax` режет заново всегда;
   - `calm` → `ots` от собеседника к X (собеседник — кто говорил перед X, а в монологе X — последний другой
     говорящий), иначе `medium` с X в составе, иначе `close` X;
   - `tense` → `close` X с выражением шага (нет точного — `neutral`, затем любой крупный план X, затем `medium`);
   - `climax` → `close` X; перед ним с вероятностью 1/3 — `angle` как перебивка (жребий — хеш `scene_id:step_index`,
     не чаще раза в 8 реплик; первая перебивка сцены — без ограничения по расстоянию).
3. **Рассказчик** (`narrate` voiceover/report) → `wide` или `insert`, чередуя; `inner` → `close` или `reaction`
   Громова (внутренний голос всегда на его лице).
4. **Реакция.** Длинная реплика (> 120 знаков на текущем языке; длину сообщает интерфейс через
   `InterpreterOptions.lineLength`) после крупного плана говорящего → `reaction` слушающего (собеседника по п. 2),
   если есть; счётчик длинных реплик копится по сцене, реакция — каждая четвёртая, потом счёт с нуля.
5. **Ритм.** Не больше трёх крупных планов подряд (`close`/`ots`/`reaction`) — дальше `medium`/`wide`; один и
   тот же кадр дважды подряд только при том же говорящем и не дольше трёх реплик (затем `medium` с X или
   `wide`); после `angle` — возврат в покрытие (`medium` или `ots`), даже если реплика напряжённая.
6. **Выбор игрока** → `medium` с Громовым или `wide`; выбор с таймером → `close` оппонента (собеседника героя),
   если он в сцене.
7. **Переходы.** Внутри сета — `cut`. Смена сцены: новый блок — `fade`; другое **место** — `dissolve` (в графике
   «Воспоминания» — растворение точками волной по диагонали, 0,9 с); другой фон того же места — `cut` (владелец
   2026-10-14: «точки только при глобальной смене локаций»). Место — `assets.backgrounds[].place` (кабинет со звонками
   и лупой, дом на Молодогвардейской — квартира и площадка, нотариус, агентство); нет поля — место совпадает с фоном.
   Переход считается от последнего **показанного** кадра: сцена из одной логики (переменные, ветвления, прыжки, звук)
   на экран не выходит, иначе её фон мелькал бы на время растворения; явный переход прыжка в неё достаётся следующей
   показанной сцене. «Оператор поправил кадр» при смене сцены выключен — кадр не дёргается (владелец 2026-10-14).
8. **Подсветка говорящего** — только в `wide`/`medium` с масками: остальные персонажи затемняются на 15 %,
  говорящий — без изменений; в `close`/`ots`/`reaction` подсветки нет.
9. **Запасной вариант.** Нет подходящего кадра (состав, выражение) → фон + спрайты, как сейчас; `show`/`hide`
   продолжают управлять спрайтами на случай отката. Ушёл персонаж (`hide`), который был в кадре, → `wide`
   оставшихся или спрайты. Шаг `bg` на другую локацию снимает покрытие до следующей сцены. Файл кадра не
   загрузился → рендерер показывает спрайты; пока кадр грузится — виден прежний.
10. **Где живёт.** `runtime/src/core/editor.ts` — чистые функции (`entryShot`, `lineShot`, `choiceShot`,
    `afterHide`, `explicitShot`), память сцены `ShotCtx` хранится в `ViewState.shot_ctx` и попадает в сейв;
    интерпретатор шлёт событие `shot` перед `speaker`, рендереры держат слой кадра между спрайтами и CG
    (`runtime/README.md`, «Кадры покрытия»). Тесты: `runtime/tests/editor.test.ts`,
    `interpreter.coverage.test.ts`.

## 5. Производство

1. Шот-лист по сетам: для каждого сета — состав, какие `kind`/`angle`/выражения нужны (по сценам, где сет
   используется), с промптами по §1a. Файл: `docs/production/ep01-shot-list.md`.
2. Объём на сет (ориентир): `wide` × 2–3 (по составу), `medium` × 3–6, `ots` × 4–8, `close` × (персонажи ×
   выражения, встречающиеся в сете), `insert` × 2–3, `angle` × 2–3, `reaction` × 2–4.
3. Порядок: кабинет прокуратуры (14 сцен) → допросная → квартира Зои Павловны → контора нотариуса → улица
   ночью → остальные.
4. Приёмка: лица и одежда — по референсам; свет мотивирован; нет текста; композиция оставляет нижнюю треть
   под окно текста в `wide`/`medium` (в `close` окно текста накладывается на грудь, не на лицо: лицо — в
   верхних двух третях).
5. Тест пайплайна (2026-10-11): 12 кадров сета «кабинет, день», сцена s12 — `assets/_tests/shots/`, оценка в журнале
   генераций: консистентность лиц и комнаты во всех крупностях и ракурсах подтверждена, ось «восьмёрки» соблюдена.
