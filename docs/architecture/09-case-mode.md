# 09. Режим дела: поиск улик в духе Criminal Case

**Черновик на утверждение, 2026-10-12.** Решение владельца: «покликал, не интересно играть — вернуться к классическому
геймплею подобных проектов»; выбран поиск улик (Criminal Case). Эпизод перестаёт быть визуальной новеллой с мини-играми:
игрок всё время действует, сюжет подаётся короткими вставками между задачами.

## Цикл главы

```
Экран дела (папка следователя)
 ├─ задачи главы ── каждая стоит ★ (кроме первой)
 │    ├─ Осмотреть место  → поиск 12 предметов на время → очки → ★★★ за скорость и точность
 │    ├─ Изучить улику    → короткий пазл (сложить обрывки, сличить подпись, перевернуть фото)
 │    ├─ Экспертиза       → Левина: база БТИ, доска связей
 │    └─ Поговорить       → 3–4 реплики, новая наводка или примета
 ├─ подозреваемые (лица) и приметы убийцы (5 штук, открываются уликами)
 └─ конец дела: арест — выбрать того, у кого все 5 примет → суд, эпилог
```

★ зарабатываются в поиске; повтор сцены даёт новый набор предметов из 25–30, поэтому сцену хочется пройти ещё раз.

след), Мурашов (все пять).

## Рамки формата

- Текст: разговор ≤ 4 реплик, рассказчик ≤ 1 строки между задачами; эпизод ≈ 150 строк вместо нынешних 864.
- Действие игрока каждые ≤ 20 секунд; экранов без действия нет.
- Предметы на сцене: зона нажатия ≥ 48 px на телефоне, поэтому 12–15 предметов за раз на кадре 16:9.
- Названия предметов — короткие существительные на 4 языках.
- Данные: новый `case`-JSON рядом с эпизодом (`schemas/case.schema.json`, линтер и пример обновляются вместе),
  `episode.schema.json` не трогаем. Короткие разговоры играет нынешний движок новеллы.

## Что берём и что новое

**Остаётся:** рантайм (движок, меню, сохранения, звук, 4 языка, Playgama), мини-игры как задачи (поиск — расширить списком
предметов, таймером, очками и ★; документы; база БТИ; доска; допрос «надавить/предъявить»), лица, спрайты, фоны, CG,
документы, ключи, факты дела. Из 333 кадров покрытия нужны ≈ 40–60 — фоны разговоров и заставки глав.

**Новое:** экран дела (задачи, ★, подозреваемые, приметы, улики, арест); формат данных дела; 6–7 насыщенных сцен для
поиска (квартира Зои, подъезд, контора, архив БТИ, улица ночью, квартира Мурашова) с разметкой 25–30 предметов каждая;
крупные планы улик для осмотра.

## Три решения (в скобках — предложение по умолчанию)

1. **Вид сцен поиска** (резче, «оперативная съёмка»): мелкие предметы не читаются в мягкости аналогового ТВ; ТВ-вид
   остаётся у заставок и разговоров.
2. **Структура** (линейные главы + арест): ветвления на 3 концовки убираем, выбор игрока — в допросах и в аресте.
3. **Монетизация** (без «энергии»): подсказка за rewarded-рекламу, interstitial между главами — по чек-листу Playgama.

## Порядок работы

1. **Серый прототип главы 1 без генерации:** экран дела + поиск на нынешних фонах квартиры и подъезда + осмотр договора +
   два разговора + папка подозреваемых; выкладка на Pages. Проверяем одно: хочется ли продолжить.
2. Если да — опыт на одной насыщенной сцене: генерация, разметка предметов с проверкой каждой рамки, сколько из 30 годятся.
3. Главы 2–3. Кредиты — только после утверждения листа задач главы: сначала логика текстом, потом генерация.

Прежний аудит логики кадров отложен: новый список сцен его заменяет.
