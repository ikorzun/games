# 06. Движок, структура проекта, сборка и CI

Статус решения: **предложено** (ADR-001). Требует подтверждения владельцем проекта,
потому что меняет набор навыков команды. Ниже — критерии, варианты, рекомендация
и то, что не меняется при любом выборе.

## 1. Критерии (в порядке веса)

1. **Playgama — основной канал** (у студии три HTML5-игры там; см. `../platform/playgama-constraints.md`):
   нужен Bridge SDK (Storage, `platform.language`, реклама, lifecycle), архив ≤ 300 МБ,
   быстрый старт на мобильном браузере.
2. **Мини-игры** — 5–6 типов с тач-управлением, свои экраны, таймеры, drag-and-drop.
3. **Четыре языка** — кириллица + латиница с диакритикой, перенос строк, +35 % длины, смена
   языка на лету, шрифты внутри сборки.
4. **Один движок для web и desktop** (Steam/itch — вторичный канал): двойной движок удваивает
   QA и локализацию (вывод исследования, `../research/01-vn-best-practices.md`, C.6).
5. **Сценарий как данные** (`schemas/episode.schema.json`) — движок исполняет JSON, а не
   хранит сюжет в своём формате.
6. Бесплатность/лицензия, порог входа для малой команды.

## 2. Варианты

| | Ren'Py | Godot 4 (+ свой интерпретатор JSON или Dialogic 2) | Unity + Naninovel | TypeScript: PixiJS-сцена + DOM-интерфейс (свой рантайм) |
|---|---|---|---|---|
| Адаптер Playgama Bridge | **нет**; web-порт на WASM без многопоточности, сейвы в IndexedDB, нужен самодельный JS-мост | официальный плагин Godot 4 | официальный пакет + WebGL-шаблон | официальный JS Core (`@playgama/bridge`), подключается напрямую |
| Web-сборка | `game.zip` ≤ 100 МБ, файлы > 50 МБ не кэшируются, «бета»-статус порта | WASM-ядро 20–27 МБ, долгая компиляция на мобильных | тяжёлый WebGL | минимальный бандл (сотни КБ ядра), мгновенный старт |
| Мини-игры | creator-defined displayables (Python), ограничены в web | нативно, максимум гибкости | нативно | нативно (PixiJS/Canvas), полная свобода |
| Текст 4 языков | хорошо (TTF, `translate`) | хорошо (CSV + `#id`) | отлично (локали, managed text) | **отлично**: DOM/CSS-текст — лучший перенос, шрифты, доступность (скринридеры) |
| Зрелость VN-функций | **эталон** (бэклог, скип прочитанного, откат, галерея, self-voicing) | Dialogic 2 — средняя, требует Godot 4.5+ | высокая | **нужно написать** (2–4 недели на ядро) |
| Desktop | отлично | отлично | отлично | Electron/Tauri + steamworks.js |
| Лицензия | MIT + части LGPL, бесплатно | MIT, бесплатно | ~$150 + Unity Personal | MIT, бесплатно |
| Исполнение нашего JSON | конвертер JSON → .rpy (генерация кода) | конвертер или интерпретатор на GDScript | конвертер в Naninovel-скрипты | **интерпретатор напрямую** |
| Порог для команды с HTML5-опытом | низкий для VN, но новый стек (Python) | средний (GDScript, редактор) | высокий (C#) | низкий (TypeScript, уже есть пайплайн HTML5-игр) |

Источник оценок — матрица C.6 исследования и официальный чеклист Playgama.

## 3. Рекомендация (ADR-001)

**Собственный рантайм на TypeScript: PixiJS для сцены и мини-игр + DOM-слой для текста и UI,
сборка Vite, Playgama Bridge через npm-пакет, desktop через Tauri (или Electron) + steamworks.js.**

Почему:
- Команда уже выпускает HTML5-игры на Playgama — стек, пайплайн загрузки архивов, проверка
  чеклиста и Bridge знакомы. Это убирает главный риск исследования («платформа выясняется
  после выбора движка — переделка»).
- Сценарий исполняется из `episodes/*.json` напрямую: линтер, экспорт локалей, автотесты и
  рантайм работают с одной моделью данных. Нет конвертеров и «второй правды».
- DOM-текст решает самые дорогие проблемы четырёх языков: переносы, диакритика, масштаб шрифта,
  скринридеры, `user-select: none`, матрица размеров экрана — всё средствами CSS.
- Бандл минимален, старт на мобильном браузере мгновенный, ассеты эпизода грузятся по требованию.
- Мини-игры — обычные PixiJS-сцены с общим интерфейсом (`IMinigame`), тач и мышь.

Цена: 2–4 недели на ядро новеллы (интерпретатор шагов, текстовое окно с typewriter-эффектом,
выборы, бэклог, скип прочитанного, авто-режим, сейвы с миграцией, галерея/архив, настройки,
смена языка) и дисциплина не изобретать то, что в Ren'Py «из коробки». Список функций для паритета
с Ren'Py — раздел 7.

**Альтернатива**, если команда предпочитает редактор и готовый VN-слой: Godot 4 с собственным
интерпретатором нашего JSON (не Dialogic — чтобы не терять модель данных) и официальным плагином
Bridge. Платим WASM-ядром и временем компиляции на мобильных.

**Не выбираем** Ren'Py как основной движок: нет адаптера Playgama, web-порт ограничен, а второй
движок для web удваивает работу. Ren'Py остаётся эталоном UX, по которому мы сверяем свой рантайм.

  runtime/                   TypeScript-рантайм (появится на этапе вертикального среза)

    src/stage/     PixiJS: фоны, спрайты, фильтры (VHS, archive_photo…), переходы
    src/ui/        DOM: текстовое окно, выборы, быстрое меню, панель дела, архив, настройки

## 5. Рантайм: контракты

- **Интерпретатор шагов.** Один `switch` по `step.do`; каждая сцена исполняется до терминального
  шага; переходы между сценами — только через `jump/branch/choice/minigame.outcomes/end`.
  Условия `when` вычисляются той же грамматикой, что в `tools/vnexpr.py`.
- **Состояние** = `{ episode_id, scene_id, step_index, vars, globals, archive[], journal[] }`.
  Сейв — этот объект + `schema_version` + `content_version`; при загрузке — миграция по версии.
  На Playgama — `bridge.storage.set(['profile','progress','settings','archive'], [...])` одним вызовом.
- **i18n.** `t(key)`: `locales/<lang>` → `en` → `ru` → `[key]` (видимая заглушка в dev-сборке).
  Смена языка — перерисовка текущего шага без перезапуска сцены.
- **Пресеты показа** (`presentation`) — набор: фильтр сцены, раскладка UI, стиль титров, поведение
  камеры. Задаются таблицей, не кодом сцен.
- **Мини-игры** — интерфейс:
  ```ts
  interface IMinigame {
    mount(root: PIXI.Container, dom: HTMLElement, cfg: MinigameConfig, ctx: GameContext): void;
    pause(): void; resume(): void;          // реклама, уход в фон (Bridge PAUSE_STATE_CHANGED)
    serialize(): unknown; restore(s: unknown): void;   // автосейв внутри мини-игры
    onResult: (r: 'success' | 'partial' | 'fail' | 'skipped') => void;
    destroy(): void;
  }
  ```
  Результат маппится в `outcomes`; `skipped` → `skip.skip_counts_as`.
- **Платформа** — интерфейс `IPlatform { language(); save(keys, values); load(keys); showInterstitial(); showRewarded(); onPause(cb); onAudio(cb); ready(); track(event) }`
  с реализациями `playgama`, `desktop`, `web-plain` (localStorage только вне Playgama).
- **Реклама** — вызывается только интерпретатором на блоках с `ad_break_allowed`, никогда из сцен.

## 6. Сборка и ассеты

- Картинки → webp (фоны q80 ≈ 150–400 КБ, слои спрайтов 50–200 КБ), аудио → ogg; суммарно
  эпизод ≈ 15–30 МБ, ядро ≈ 5 МБ; сезон из 8 эпизодов укладывается в 300 МБ с запасом,
  но грузится по эпизодам (манифест на эпизод).
- Шрифты — внутри сборки, сабсет: кириллица + латиница-1 + латиница-расширенная-A.
- Один скрипт `build_assets` считает бюджет (`assets.budget_mb`) и падает при превышении.
- Имена файлов — только `[a-z0-9_./-]` (линтер проверяет пути в `assets`).

## 8. CI и качество

- `validate-content` (уже есть): схемы парсятся, каждый эпизод проходит линтер, самотест грамматики.
- На этапе рантайма: `vitest` для интерпретатора (прогон всех сцен эпизода «автопилотом» по всем
  вариантам выборов — проверка, что каждая ветка доходит до `end`), Playwright-смоук сборки:
  загрузка → `game_ready` → первый выбор → сейв/лоад → смена языка → скриншоты по матрице
  360×640, 390×844, 915×412, 1280×720, 2560×1440 на 4 языках.
- Псевдолокализация как отдельный «язык» `xx` в dev-сборке (+35 % длины, диакритика).

## 9. Открытые вопросы к владельцу

1. Подтвердить ADR-001 (TypeScript-рантайм) или выбрать Godot 4.
2. Desktop: Tauri (меньше, нужен Rust-тулчейн) или Electron (проще, +150 МБ).
3. Озвучка рассказчика на русском: да/нет (влияет на бюджет и на `voice`-поля).
