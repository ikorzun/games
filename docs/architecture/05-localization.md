# 05. Локализация: русский → английский, испанский, португальский

## 1. Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Язык-источник | `ru` | сценарий пишется на русском, реалии 90-х — русские |
| Обязательный язык | `en` | требование Playgama (default + fallback); международный мостик для es/pt-переводчиков |
| Варианты испанского | нейтральный латиноамериканский (`es`, ориентир es-419) | крупнейшая аудитория веб-порталов — Мексика/Латинская Америка; избегаем регионализмов |
| Варианты португальского | бразильский (`pt`, ориентир pt-BR) | Бразилия — на порядок больше Португалии по аудитории; европейская норма понятна бразильцам хуже, чем наоборот |
| Fallback | `lang → en → ru` | строка никогда не пустая; линтер не пропускает эпизод без полного `en` |
| Способ хранения | плоские JSON `locales/<lang>/<episode_id>.json` + `locales/<lang>/ui.json` | просто для скриптов, Crowdin/Weblate понимают, diff читаем |
| Ключи | стабильные, по структуре сцены: `ep01.s03.l012`, `ep01.s03.c1.a`, `ui.menu.save` | не зависят от текста источника → правка русской строки не ломает переводы |
| Переводят | машинный черновик (LLM с глоссарием и стайлгайдом) → редактор-носитель → LQA в игре | дёшево и быстро, при этом качество контролирует человек |

## 2. Структура

```
locales/
  ru/ ep01_murylev.json   ui.json   common.json
  en/ ep01_murylev.json   ui.json   common.json
  es/ ...
  pt/ ...
  _export/ ep01_murylev.csv     ← для переводчиков (key, context, ru, en, es, pt)
docs/localization/
  styleguide-en.md  styleguide-es.md  styleguide-pt.md
  glossary.md                      ← реалии 90-х, сленг, должности, аббревиатуры
```

Инструменты: `tools/loc_sync.py` (`skeleton` / `export` / `import` / `stats`) и
`tools/validate_episode.py` (пропущенные ключи, неиспользуемые ключи, пустые строки,
расхождение плейсхолдеров `{name}` между языками).

Статус перевода хранится в эпизоде: `localization.status.<lang>` ∈
`none → machine → draft → edited → lqa → final`. Релиз эпизода возможен при
`ru: source`, `en: final`, `es/pt: ≥ edited`.

## 3. Пайплайн

1. **Сценарий на русском** → линтер зелёный → `loc_sync skeleton` создаёт пустые ключи во всех языках.
2. **Заморозка строк** (string freeze) для эпизода: после неё правки ru только через
   тикет; ключи не удаляются до конца цикла.
3. **Глоссарий эпизода**: сценарист помечает реалии, имена, прозвища, аббревиатуры, цитаты
   из документов; переводчик получает стратегию для каждого термина (раздел 5).
4. **Машинный черновик** `en` (из `ru`), затем `es` и `pt` (из `ru` с `en` как опорой) —
   с системным промптом: стайлгайд языка, глоссарий, правила длины для кнопок и титров,
   контекст из колонки `context` экспорта (кто говорит, какой тип шага).
5. **Редактура носителем**: обязательна для всех реплик персонажей и титров; для
   документов — проверка юридической/канцелярской лексики эпохи.
6. **Псевдолокализация** (`[!!! Ţéxţ !!!]`, +35 % длины) — автоматический прогон UI и
   кнопок до того, как придут реальные переводы: ловим обрезания и переполнения.
7. **LQA в игре**: прохождение на каждом языке по скриншот-матрице разрешений; проверка
   шрифтов (диакритика), переносов, таймеров (длинные строки es/pt на таймерных выборах).
8. **Финализация** статуса и релиз.

## 4. Объёмы и длина

- Общие ориентиры из исследования: ru → en короче на 10–20 %, en → es/pt длиннее на 15–30 %.
- **Замер на эпизоде 1** (131 строка): en длиннее ru на ~12 % по символам, es и pt длиннее en на
  3–4 %; зато короткие строки (титры, заголовки, промпты выборов) растут на 45–100 %
  (`s19.cap` 17 → 30, `mg_docs.title` 14 → 25). Вывод: UI текстового окна проектируется под +35 %
  к английскому, а **титры, кнопки и заголовки — под +100 %**; главный риск переполнения — титры.
- Кнопка выбора: ≤ 60 символов в любом языке; титр `date_stamp`: ≤ 32; `lower_third`: ≤ 48.
- Эпизод на 45 минут ≈ 12–18 тыс. слов русского текста → ×3 языка перевода. Оценка
  стоимости — в `../production/roadmap.md`.

## 5. Реалии 90-х: стратегии перевода

Главная локализационная проблема проекта — не грамматика, а **мир**: ОПГ, стрелка,
крыша, общак, авторитет, вор в законе, опер, следак, ИВС, СИЗО, ОРМ, ОБЭП, РУОП,
ваучер, обналичка, «кидалово», «малиновый пиджак», хрущёвка, электричка, дача, ЖЭК, БТИ,
нотариус, «Волга», «девятка». Стратегии (фиксируются в `glossary.md` по каждому термину):

| Стратегия | Когда | Пример |
|---|---|---|
| **Функциональный эквивалент** | есть близкое понятие в культуре языка | «крыша» → en *protection*, es *protección*, pt *proteção*; «опер» → en *detective*, es *agente*, pt *investigador* |
| **Транслитерация + пояснение при первом появлении** | термин — часть колорита и повторяется | «стрелка» → *strelka — a gangland sit-down*; далее просто *strelka* |
| **Описательный перевод** | понятие институциональное | ИВС → *temporary detention cell*, СИЗО → *pre-trial detention centre / remand prison* |
| **Сохранение + архивная справка** | реалия важна исторически | «ваучер» → *voucher* + запись в архиве «Приватизационный чек, 1992» |
| **Замена на нейтральное** | сленг без эквивалента, не несущий сюжетной нагрузки | «кидалово» → *scam / estafa / golpe* |

Правила:
- Имена и фамилии — по таблице имён эпизода. en: упрощённая транслитерация в духе англоязычной
  прессы (*Andrei, Sergei, Saiko, Chikatilo*), не строгая BGN/PCGN. es: та же основа с адаптацией
  под чтение носителя — ударения (*Andréi, Grómov, Kúntsevo*), *g* → *gu* перед *e/i* (*Serguéi,
  Kovriguin*), *Presnia*. pt-BR: адаптированные формы (*Serguei, Zoia, Viktorovitch* — «ч» → *tch*,
  *Presnia*). Отчества сохраняются (*Pavlovna*). Новые адаптации вводит только таблица имён, не переводчик.
- Прозвища переводятся по смыслу («Удав» → *The Boa* / *La Boa* / *A Jiboia*) и фиксируются в глоссарии.
- Звания и должности: следователь по особо важным делам → *senior investigator for major cases*;
  оперуполномоченный → *detective (operative)*; прокурор — прокурор.
- Названия статей УК — переводить описательно, номер статьи сохранять в `caption fact`.
- Деньги — рубли оставляем, с подсказкой масштаба в архиве («средняя зарплата 1994 — …»).
- Мат и грубая лексика: источник — умеренный (как в передаче); в переводе — тот же регистр, без усиления.

## 6. Типографика по языкам

| | ru | en | es | pt (BR) |

| кавычки | «…» („…“ внутренние) | “…” (‘…’) | “…” (‘…’ внутренние; « » только в испанской норме, не для es-419) | “…” (‘…’) |
| тире в диалогах | — (длинное) | — | — (raya) | — (travessão) |
| вопрос/восклицание | ? ! | ? ! | ¿…? ¡…! | ? ! |
| дата | 12 октября 1994 | October 12, 1994 | 12 de octubre de 1994 | 12 de outubro de 1994 |
| числа | 1 500 (пробел), 2,5 | 1,500 / 2.5 | 1,500 / 2.5 (CLDR es-419, норма Мексики) | 1.500 / 2,5 |
| десятичные | запятая | точка | точка | запятая |
| неразрывные пробелы | перед «—», после «№», в датах — расставляет скрипт типографики при сборке, в исходниках не ставим | — | перед ¿¡ не нужны | — |

Шрифты — см. `03-visual-language.md` §8: один набор для всех языков, с проверкой глифов.

## 7. Локализуемые не-текстовые вещи

- **Документы и вывески:** изображение без текста + текстовый слой (ключи `text_key`). Для en/es/pt
  документ показывается как русский бланк с переключателем «оригинал / перевод»: аутентичность для
  зарубежного игрока сохраняется, а проверка документов (`document_check`) работает на всех языках.
- **Слоты реконструкции** (`reconstruction`, `deduction_fill`): грамматически нейтральные подписи
  («Орудие: ___», «Место: ___»), а не вставка слов в живое предложение — иначе падежи ru и род/число
  es/pt ломают фразу; плитки банка слов с автоуменьшением шрифта.
- **Мини-игры:** все подписи, подсказки, названия улик — ключи; `localized_assets`
  для редких случаев, где текст «впечатан» (газетная вырезка) — по версии на язык.
- **Карта:** названия улиц — ключи; при `inspired` — вымышленные.
- **Голос рассказчика:** только ru; в остальных языках — текст (поле `voice` игнорируется).
- **Титры заставки:** название эпизода — ключ; шрифт один на все языки.
- **UI-строки платформы:** названия языков всегда на самих языках
  (Русский / English / Español / Português) — требование Playgama.

## 8. Контрольные точки качества

- Линтер: 0 пропущенных ключей в `ru` и `en`, 0 расхождений плейсхолдеров — блокирующее.
- Псевдолокализация: 0 обрезаний на матрице 360×640 … 2560×1440.
- Глоссарий: каждая запись имеет перевод на 3 языка и стратегию.
- LQA-отчёт на язык: список найденных проблем с ключами, закрыт до релиза.
- Шрифтовой тест: строка-«панграмма» с диакритикой каждого языка рендерится во всех стилях.
