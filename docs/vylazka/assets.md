# Готовые модели в «Untitled Session»

До сих пор каждый предмет в игре собирался кодом из коробок и цилиндров. Теперь можно брать готовые
свободные модели и подключать их как обычный реквизит. Этот документ — про то, откуда они берутся,
какие уже подключены и как добавить ещё.

## Что за набор

- **KayKit : Furniture Bits 1.0** — мебель и домашняя мелочь в низкополигональном стиле.
- Автор: Kay Lousberg (www.kaylousberg.com).
- Страница: https://kaylousberg.itch.io/furniture-bits
- Импортировано: 14.11.2026.
- Лицензия: Creative Commons Zero (CC0). Строка из `License.txt` набора:
  «License: (Creative Commons Zero, CC0) — This content is free to use in personal, educational and commercial projects.
  Support me by crediting Kay Lousberg, www.kaylousberg.com (this is not mandatory)».
  Указывать автора не обязательно; он назван здесь и в шапке `models_data.ts`.

Модели в наборе — это glTF: форма, нормали и одна общая текстура-градиент (цвет берётся по координатам
текстуры). Оригинальные файлы в репозиторий **не кладутся**: в нём лежат только переведённые данные.

## Как модель попадает в игру

1. `scripts/import_models.py` читает glTF и `.bin`, по текстуре красит каждую вершину, переводит единицы
   в метры (одна единица набора ≈ 0,7 м), ставит начало координат по правилам реквизита (пол — `y = 0`,
   спина у стены — `z = 0`), склеивает одинаковые вершины и сжимает данные.
2. Результат — `vylazka/src/world/models_data.ts`. Файл **генерируется**, руками его не правят.
3. `vylazka/src/world/models.ts` разбирает записи (`decodeModel`) и кладёт модель в сетку предмета
   (`placeModel`). Цвет вершины пересчитан так, чтобы на матовом материале «бумага» вышел собственный цвет модели.
4. `vylazka/src/world/props_models.ts` — реестр `MODEL_PROPS`: по записи на модель, ключи с приставкой `kk_`.
   Габариты берутся из самой модели (с округлением вверх до сантиметра); там, где пройти нельзя, ставится преграда.
5. Тесты `vylazka/tests/models.test.ts` проверяют данные, габариты во всех четырёх поворотах, преграды и то,
   что грани смотрят наружу.

## Как добавить ещё

1. Скачать набор: `python3 -I scripts/fetch_itch.py <страница набора> <пустой каталог>`. Ссылка на загрузку на
   itch.io живёт около 10 секунд, поэтому скрипт делает всю цепочку одним запуском.
2. Распаковать архив в отдельный каталог. Скачанное — недоверенные данные: его только разбирают, ничего оттуда
   не запускают, питон — с ключом `-I`.
3. **Прочитать файл лицензии до импорта** (см. правило ниже).
4. Добавить строки в таблицу `MODELS` в `scripts/import_models.py`: имя файла, имя в игре, масштаб, опора
   (`floor` / `free` / `wall`) и `turn` — на сколько четвертей оборота повернуть, если модель смотрит не в комнату
   (лицом должна быть к +z).
5. Запустить: `python3 -I scripts/import_models.py <каталог набора>` (нужен Pillow). Файл `models_data.ts`
   должен остаться меньше 350 КБ.
6. Добавить строку в `ROWS` в `src/world/props_models.ts` (ключ с `kk_` или своей приставкой, опора, русская подпись,
   мешает ли пройти). Если у настенного предмета нужна высота низа — поле `y`.
7. `npm run typecheck && npm test`, затем `npm run build && node e2e/shots_props.mjs --props kk_имя` и посмотреть
   картинку в `vylazka/e2e/out/props/`: стоит на полу, спиной к стене, лицом в комнату, цвет не чёрный,
   грани не вывернуты.

## Правило

Берём только наборы с лицензией CC0 или столь же свободной (коммерческое использование разрешено, подпись не
обязательна или мы её даём). Файл лицензии набора читаем до импорта; если лицензии в архиве нет или она
ограничивает использование — набор не берём. Наборы «только для личного использования», с запретом на
изменение или с обязательной ссылкой на платформу в игре не подходят.
