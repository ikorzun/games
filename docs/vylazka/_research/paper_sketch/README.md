# Набросок: огромные бумажные цветы

Исследовательский код к записи V-11 в `ideas.md`. Не часть игры: в сборку, тесты и CI не входит.

Поводом стали фотографии владельца с выставки: гирлянда бумажных цветов в рост человека под
потолком тёмного зала. Чужая работа не воспроизводится: цветы взяты «из этой жизни» — гвоздика,
георгин, тюльпан, физалис, одуванчик — и повешены в нашу жилую комнату убежища.

- `paper.ts` — генераторы поверхностей (лепесток с изгибом и волнистым краем, тело вращения
  с рёбрами, трубка по кривой), посев точек и черновой программный рендер.
- `mk.py` — переводит сырые кадры в PNG (нужен Pillow).
- `paper_room.jpg` — общий вид.

Запуск (из каталога `vylazka/`, нужны его `node_modules`):

```bash
S=../docs/vylazka/_research/paper_sketch; mkdir -p /tmp/paper
npx esbuild $S/paper.ts --bundle --platform=node --format=esm --outfile=/tmp/paper/paper.mjs
P=/tmp/paper node /tmp/paper/paper.mjs && P=/tmp/paper python3 $S/mk.py
```

Что набросок показал. Крупные листы бумаги читаются, и огромность видна сразу — рядом с телевизором
и торшерами. Но при потолке 2,7 м цветы висят не над головой, а на уровне лица: сад «под потолком»
возможен только отдельным высоким местом. Тонкое (одуванчик, тычинки, нити подвеса) теряется.
Генераторы — лепесток, тело вращения, трубка по кривой — те самые инструменты формы, которых
не хватает сборщику геометрии игры (`modeling.md`).
