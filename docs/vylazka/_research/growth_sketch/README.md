# Набросок: грибница по облаку точек

Исследовательский код к `docs/vylazka/growth.md`. Не часть игры: в сборку, тесты и CI не входит.

- `growth.ts` — микродвижок, 145 строк чистого TypeScript без зависимостей: граф соседей по точкам,
  нити (кончик идёт, ветвится, упирается), налёт вокруг нитей, грибы из точек. Один сид — один результат.
- `sketch.ts` — берёт жилую комнату убежища (сид 20041113, предмет № 28 — тумба с телевизором), сеет
  по ней точки, запускает рост и рисует кадры простым программным рендером.
- `mk.py` — переводит сырые кадры в PNG, листы и GIF (нужен Pillow).
- `sheet_plan.jpg`, `sheet_view.jpg` — шесть моментов роста: вид сверху и вид из камеры.

Запуск (из каталога `vylazka/`, нужны его `node_modules`):

```bash
S=../docs/vylazka/_research/growth_sketch; mkdir -p /tmp/growth
npx esbuild $S/sketch.ts --bundle --platform=node --format=esm --outfile=/tmp/growth/sketch.mjs
OUT=/tmp/growth T=110 MUSH=0.02 node /tmp/growth/sketch.mjs && OUT=/tmp/growth python3 $S/mk.py
```

Замер на 125 тысячах точек (комната 9 × 9 м, шаг между точками 3,3 см, около миллиона рёбер): граф —
300 мс, нити — 36 мс, налёт — 28 мс, грибы — 32 мс. Для игры граф надо считать не по всем точкам, а по
узлам с шагом 8–10 см (`growth.md`, §7).

Что в наброске плохо: чёрные точки на стене — дыры чернового рендера; рост почти весь на полу (все
зародыши на полу); грибы мелкие и появляются поздно.
