# Набросок: комната кружевом

Исследовательский код к `docs/vylazka/untitled_session.md` (§2, «Кружево») и к записи V-09 в
`ideas.md`. Не часть игры: в сборку, тесты и CI не входит.

Поводом стали три фотографии владельца с выставки: стены дома, сотканные белой нитью на прозрачной
основе. Здесь тот же подход приложен к нашей комнате — жилой комнате убежища (сид 20041113, тумба
с телевизором). Чужая работа не воспроизводится: комната, вещи и рисунок свои.

- `lace.ts` — берёт геометрию комнаты и рисует только нити: **шнур** (швы «кладки», контуры граней,
  рваный край стены, план на полу) и **уток** (тонкое заполнение). Заливки нет, всё видно насквозь;
  стены неполные, с дырами, вверх уходят нити подвеса.
- `mk.py` — переводит сырые кадры в PNG (нужен Pillow).
- `lace_room.jpg` — вид из угла: сверху как есть (1280 × 720), снизу тот же кадр в разрешении слабого
  качества игры (640 × 360). Шнуры читаются и там; частое заполнение сливается в тон.
- `lace_room_front.jpg` — вид от тумбы. Хуже: книжный шкаф справа даёт кашу из нитей.

Запуск (из каталога `vylazka/`, нужны его `node_modules`):

```bash
S=../docs/vylazka/_research/lace_sketch; mkdir -p /tmp/lace
npx esbuild $S/lace.ts --bundle --platform=node --format=esm --outfile=/tmp/lace/lace.mjs
L=/tmp/lace B_X=-4.2 B_Z=-11.5 T_X=-1.0 T_Z=-14.0 T_Y=1.2 node /tmp/lace/lace.mjs && L=/tmp/lace python3 $S/mk.py
```

Что набросок показал: комната читается и с одними шнурами; рисунку нужен крупный шаг; плотные вещи
(шкаф с книгами) надо прореживать; пустой пол просит плана покрупнее, чем линия у стен.
