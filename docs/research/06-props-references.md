## 7. Что не удалось и ограничения

- Изображения кандидатов не скачивались и, за одним исключением, не просматривались: по брифу «ничего не скачивать на диск». Проверка = страница/метаданные открываются и содержат нужный предмет. Визуальная проверка остальных кандидатов (особенно п. 5-1, п. 6-1, п. 1а-2, 1б-3, п. 4-2) возможна только через сохранение файла в служебный кэш инструмента (fetch → просмотр); **не выполнялась из-за запрета, может быть выполнена по отдельному разрешению**.
- Исключение: при запросе файла «Ключ СССР 1960.JPG» инструмент загрузки сам сохранил его в служебный кэш `/Users/ikorzyn/.claude/projects/-Users-ikorzyn-Desktop-Claude-CriminalRussia/7d831296-a78c-43b6-8ee4-a45c40a92223/tool-results/webfetch-1791824073980-k4litr.jpg` (вне репозитория); файл просмотрен, описание в п. 1а.
- 403 для бота: auction.ru, etsy, rusneb.ru; капча: farpost.ru; avito.ru закрыт для инструмента; festima.ru — 503; goskatalog.ru — «connection refused» (Госкаталог **не проверен**, по брифу один из предпочтительных источников). Всё, что взято с этих хостов, — по названию лота/записи из индекса Bing Images/WebSearch, помечено «проверить вручную».
- Часть сайтов (pikabu, dverizamki.org, farpost) при загрузке отдаёт текст в битой кодировке — содержимое не прочитано.
- Расхождения между источниками: (а) Commons «Нотариальная доверенность РФ.png» — PD в лицензии, CC-BY-SA-3.0 в категориях; (б) Commons «Dzhalil apartment key» — автор Kirillin (описание) против Engelberthumperdink (категории); (в) Commons «20180626 Extract …» — «источник» не относится к документу; (г) «Ключ СССР 1960» — год только в названии, в метаданных 2014 (год съёмки).
- Мешок/Avito/eBay по ключам и документам эпохи — вручную в браузере (боту недоступны).
