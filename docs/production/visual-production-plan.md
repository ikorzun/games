# План визуального производства: генеративный пайплайн вертикального среза

Цель — собрать визуальную часть пилота «Смерть за квартиры» (`episodes/examples/ep01_murylev.json`)
генеративными инструментами так, чтобы (а) утвердить стиль сезона на реальных картинках,
(б) получить фоны, документы и видео-вставки уровня «можно показывать», (в) получить
персонажей-плейсхолдеры, которые художник доведёт до спрайтов с наборами выражений.

Инструменты: подключённый Higgsfield — видео **Seedance 2.0 / 2.0 Mini / 2.5** (ByteDance),
картинки **Nano Banana Pro** (Google) и **GPT Image 2.5** для фонов, CG, документов и UI, **Soul Cast**
для консистентных персонажей. Промпты и параметры — в `prompts/`.

## 1. Что в новелле видео, а что статика

| Элемент | Формат | Почему |
|---|---|---|
| Заставка эпизода (`title_card`) | видео 6–8 с, луп | фирменный момент: шум телевизора → красная плашка; название накладывает рантайм (текст в видео не генерируем) |
| Холодное открытие (`cold_open`) | один «живой» кадр 8 с, луп + статичный фон-дубль | движение камеры и мерцание окон дают «документальность»; статичный дубль нужен для портретного режима и слабых устройств |
| Главное меню | луп 8 с (видеосалон, телевизор, полка кассет) | рамка сезона |
| Склейка `vhs_glitch` | один общий клип 2–4 с | один на всю игру |
| Хроника (`chronicle`) | статика + Ken Burns в рантайме | дешевле и легче видео; при желании image-to-video из того же кадра |
| Реконструкции, следствие, допрос, суд | статика + спрайты + CG | классическая VN; видео здесь удорожает и утяжеляет |
| Эпилог (`montage`) | статика + титры | |

Веб-бюджет: клип ≤ 2.5 МБ (720p, H.264/WebM, 8 с, без звука), не более 5 клипов на эпизод и
2 общих на сезон; картинки — webp (фон 1920×1080 ≈ 250 КБ). Итог укладывается в бюджет
`assets.budget_mb` эпизода (25 МБ).

## 2. Этапы

| # | Этап | Что делаем | Выход | Критерий |
|---|---|---|---|---|
| 0 | **Стиль-тест** (сейчас) | 2–3 картинки (фон квартиры, кабинет, уличный кадр) + 1 клип 4 с по стайл-библии | референс-картинки стиля | владелец утверждает «это наш телевизор 1993 года» |
| 1 | Референсы | утверждённые картинки становятся `image_references` для всех следующих генераций; фиксируем формулировки стиля | `prompts/style-bible.md` обновлён | одна строка стиля во всех промптах |
| 2 | Фоны | 10 фонов пилота (см. `prompts/ep01-images.md`), по 2–4 варианта на фон, отбор, апскейл до 2k | `assets/ep01/bg/*.webp` | без текста/логотипов/современных предметов; палитра архетипа |
| 3 | Персонажи | Soul Cast: 9 персонажей — базовая поза, три четверти, нейтральный фон; затем выражения через image-to-image с референсом; финальную чистку слоёв делает художник | `assets/ep01/sprites/<id>/` | один человек узнаваем во всех выражениях |
| 4 | CG и документы | 3 CG + 4 бланка документов без текста + заставка-плашка + текстура папки | `assets/ep01/cg`, `assets/ep01/docs` | текст накладывает рантайм |
| 5 | Видео | заставка, холодное открытие, меню, склейка (Seedance 2.0, 720p, без звука) | `assets/common/video`, `assets/ep01/video` | ≤ 2.5 МБ, луп без шва |
| 6 | Пост и сборка | VHS-фильтр НЕ впечатываем (его даёт рантайм по `stage.filter`); конвертация webp/webm; манифест; проверка веса | обновлённый `assets` в JSON эпизода | линтер зелёный, бюджет не превышен |

Правило этапов 2–5: батчи промптов, конвертацию и подсчёт веса делают младшие агенты
(`content-linter`, см. `CLAUDE.md`); отбор вариантов и утверждение — старшая модель и владелец.

## 3. Консистентность стиля

1. **Одна строка стиля** (`prompts/style-bible.md`, §1) стоит в начале каждого промпта.
2. **Референсы**: после стиль-теста 2–3 утверждённые картинки передаются как `image_references`
   (Nano Banana Pro, Seedance 2.x) — модели держат палитру и фактуру.
3. **Персонажи**: Soul Cast даёт устойчивую «личность»; выражения генерируются от базового
   кадра, а не заново; итоговые слои (тело + лицо) режет художник.
4. **Фильтры и титры — в рантайме**: картинки генерируются «чистыми», VHS-зерно, сканлайны,
   виньетку и титры накладывает движок по `presentation`/`stage.filter`. Иначе фильтр
   невозможно отключить в режиме 16+ и нельзя переиспользовать фон в другом блоке.
5. **Журнал генераций**: для каждого ассета — промпт, модель, параметры, job id (в `prompts/`
   и в `assets/<ep>/generation-log.md`), чтобы воспроизвести или доработать.

## 4. Ограничения и этика (обязательны)

- Никаких реальных людей: ни фигурантов дел, ни узнаваемых лиц; персонажи — вымышленные типажи.
- Никаких элементов передачи: заставки, логотипа, кадров, типографики «Криминальной России».
- В картинках нет текста (вывески, бланки, газеты — пустые плашки; текст даёт локаль).
- Насилие не изображается: деталь, последствие, пустая квартира, опечатанная дверь.
- Дисклеймер об ИИ-контенте на Steam/itch; в титрах — «иллюстрации созданы с помощью
  генеративных моделей и доработаны художником».

## 5. Кредиты и объём

Текущий баланс Higgsfield — 13 кредитов на бесплатном плане: хватает на стиль-тест, не на
батчи. Оценка полного пилота: 10 фонов × 3 варианта + 9 персонажей × (1 база + 3 выражения) +
3 CG × 2 + 4 документа + 5 UI + 4 клипа × 2 дубля ≈ **110–130 генераций**. Стоимость одной
генерации — по preflight (`get_cost`) перед батчем; план пополнения — решение владельца.

## 6. Приёмка ассета

- Соответствует палитре архетипа (`docs/architecture/03-visual-language.md` §3) и режиму показа блока.
- Композиция оставляет место под текстовое окно (нижняя треть) и под спрайты (центр).
- Нет текста, логотипов, водяных знаков, современных предметов (пластиковые окна, LED, смартфоны).
- Портретный кроп по центру не теряет смысл кадра.
- Вес после конвертации в бюджете; имя файла — латиница по `assets[].path` в JSON.
