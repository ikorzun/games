# Производство: объёмы, оценки, порядок работ

Цифры ниже — из исследования `../research/01-vn-best-practices.md` (разделы A, B, F, H)
и чеклиста Playgama. Это ориентиры для планирования, не смета.

## 1. Что считаем «эпизодом» и «сезоном»

| Единица | Объём текста (ru, одно прохождение) | Общий объём с ветками (×1.3–1.5) | Время игры | Ассеты |
|---|---|---|---|---|
| Эпизод | 8–12 тыс. слов | 11–18 тыс. слов | 40–60 мин | 12–16 фонов, 6–9 персонажей (3 сквозных + 3–6 эпизодных), 3–5 CG, 4–6 документов, 4–6 мини-игр |
| Двухчастный эпизод (сага об ОПГ) | 16–22 тыс. слов | 22–33 тыс. | 90–120 мин | ×1.7 |
| Сезон (8 эпизодов, 2 из них двухчастные) | 80–100 тыс. слов | 110–150 тыс. | 6–8 ч | ~110 фонов, ~40 персонажей, ~30 CG |

Ориентир сообщества: 10 тыс. слов ≈ 45–60 мин чтения в VN. Пример `episodes/examples/ep01_murylev.json`
(вертикальный срез) содержит ~1.3 тыс. слов — это **скелет** на 14 блоков; полный эпизод —
в 8–10 раз больше текста при той же структуре.

## 2. Порядок работ (почему именно такой)

| # | Этап | Выход | Критерий готовности |
|---|---|---|---|
| 0 | **Решения** | ADR-001 (движок), уровень фикционализации по умолчанию, состав сезона 1 (`season-1-slate.md`), этическое ТЗ. Принято: лицензия есть, юридической проверки нет, русский — первоисточник | подписано владельцем |
| 1 | **Библия сезона** | мир и эпоха (хроника 1992–1997), сквозная следственная группа (3 персонажа: биографии, арки на сезон), глоссарий реалий, стайлгайд рассказчика, визуальная библия (палитры по архетипам, типажи) | документы в `docs/` |
| 2 | **Вертикальный срез** | ep01 в полном объёме текста + рантайм ядра + 2 мини-игры (`crime_scene_search`, `interrogation_press`) + Bridge (язык, сейвы, interstitial, `game_ready`) + ru/en; **загружен в песочницу Playgama** | проходится на телефоне и десктопе, чеклист Playgama закрыт, линтер зелёный |
| 3 | **Сценарии сезона** | аутлайны всех эпизодов по шаблонам блоков → полные тексты → script lock | каждый эпизод: линтер зелёный, ритм (выбор каждые 3–5 мин) проверен автопрогоном |
| 4 | **Арт** | по приоритетам P0/P1/P2; сначала сквозные персонажи и общие фоны (кабинет, допросная, суд), потом эпизодные | плейсхолдеры заменены, бюджет МБ соблюдён |
| 5 | **Мини-игры** | остальные 4 типа + конфиги по эпизодам | каждая ≤ 3 мин, пропускаема, тач + мышь |
| 6 | **Звук** | тема, 5 лупов на сезон + 2–3 на архетип, SFX/эмбиент; озвучка рассказчика (ru) — по решению | лицензии задокументированы |
| 7 | **Локализация** | после script lock: ru→en (переводчик + глоссарий) → en/ru→es, pt-BR носителями; псевдолокализация; LQA по всем веткам | статусы `final`/`edited` в эпизодах |
| 8 | **Релиз** | Playgama (чеклист 36 пунктов), затем itch/Steam (Tauri/Electron, Steam Cloud, AI-дисклеймер, контент-рейтинг 18+) | смоук-тест опубликованной ссылки |

Ключевое правило исследования: **вертикальный срез в песочнице Playgama до заказа основного
арта**, потому что ограничения платформы (Bridge, 300 МБ, тач, ориентации) могут поменять
движок и формат ассетов.

## 3. Оценки трудозатрат (сезон 1, 8 эпизодов)

| Работа | Оценка | Основание |
|---|---|---|
| Рантайм ядра + платформа | 4–6 недель (1 разработчик) | паритет с Ren'Py, раздел 7 в `06-engine-and-pipeline.md` |
| Мини-игры (6 типов, конфигурируемых) | 6–9 недель суммарно | ~1–1.5 недели на тип с тач-управлением и сейвом состояния |
| Сценарий | 10–14 недель (1 сценарист) | 100–150 тыс. слов с проверкой фактов по источникам |
| Арт | 120–160 человеко-дней художника | фон 4–5 дн, набор спрайтов 3–4 дн, CG 4–5 дн (devlog-данные); сквозные персонажи и общие фоны амортизируются на сезон |
| Звук | 3–5 недель или сток | постмортем: композитор «в целом не нужен» для бюджетной VN |
| Перевод (3 языка) | 100 тыс. слов × 3 × €0.09–0.14 ≈ €27–42 тыс. у вендоров; дешевле — фрилансеры-носители + LLM-черновик + редактура | ставки B.5 исследования |
| LQA | 2–3 недели на язык по всем веткам, web (портрет/ландшафт) + desktop | |

## 4. Бюджет ассетов на эпизод (веб)

| Тип | Кол-во | Вес | Итого |
|---|---|---|---|
| Фоны (webp q80, 1920×1080) | 14 | 250 КБ | 3.5 МБ |
| Слои спрайтов | 60 | 120 КБ | 7 МБ |
| CG | 4 | 400 КБ | 1.6 МБ |
| Документы | 5 | 200 КБ | 1 МБ |
| Музыка (ogg, лупы 1.5–2.5 мин) | 3 эпизодных + общие | 1.5 МБ | 4.5 МБ |
| SFX/эмбиент | 12 | 100 КБ | 1.2 МБ |
| **Итого на эпизод** | | | **≈ 19 МБ** (`budget_mb: 25`) |

Общее ядро (UI, шрифты, тема, сквозные спрайты, общие фоны): ≈ 15–20 МБ. Сезон из 8 эпизодов
≈ 170–220 МБ — укладывается в 300 МБ, но грузится по эпизодам.

## 5. Команда (минимальная)

| Роль | Загрузка |
|---|---|
| продюсер / геймдизайнер (владелец) | постоянно |
| сценарист с фактчекингом | полная на этапах 1–3, затем правки |
| разработчик TypeScript (рантайм, мини-игры, платформа) | полная |
| 2D-художник (фоны, спрайты, CG) | полная на этапе 4 |
| переводчики-носители en/es/pt-BR + редактор | этап 7 |
| консультант — следователь/прокурор в отставке (процедуры, лексика, фактчекинг) | по эпизоду |

MIIP-урок: «соло-ядро» к шестому месяцу обрастает подрядчиками — закладывать это в бюджет сразу.

## 6. Риски и ответы

| Риск | Ответ |
|---|---|
| Платформенные ограничения ломают формат | вертикальный срез в песочнице Playgama до арта (этап 2) |
| Юридические претензии живых фигурантов и семей жертв | уровень `dramatized/inspired` по умолчанию, изменённые имена частных лиц, без реальных фото, без интерактивного насилия |
| Переводы «плывут» при правках сценария | script lock, стабильные ключи, статусы перевода в эпизоде, линтер плейсхолдеров |
| Мини-игры растягивают прохождение и раздражают | ≤ 3 мин, диегетичные, пропускаемые, результат — улика/флаг, а не game over |
| Перерасход арта | послойные спрайты, 3 сквозных персонажа, общие фоны на сезон, P0/P1/P2 |
| Сейвы ломаются обновлениями | сейв = `scene_id + step_index + vars` с версией и миграцией; тест загрузки старых сейвов в CI |
| AI-контент и правила магазинов | дисклеймер на Steam/itch; AI только для черновиков и текстур, персонажи — у художника |

## 6a. Монетизация и выпуск (из исследования рынка)

| Канал | Модель | Обоснование |
|---|---|---|
| Web (Playgama и др. порталы через Bridge) | free-to-read; interstitial только между главами (раз в 8–12 минут чтения); rewarded — «подсказка консультанта» и «пропустить мини-игру» (одновременно доступность); покупка сезона там, где есть платежи (10 из 25 платформ), иначе «глава за рекламу» | чеклист Playgama; покрытие Bridge; критика платных «премиум-выборов» (Episode/Choices) как этически токсичных для true crime — не используем |
| Desktop (Steam, VK Play, itch) | премиум-антология + DLC-сезоны; эпизод 1 — бесплатная демо | путь The Roottrees Are Dead: бесплатный web-прототип → платная расширенная версия |
| Ритм выпуска | сезон = 6–8 дел; эпизод 1 бесплатно на web; далее эпизод в 4–6 недель на web (главы еженедельно), desktop-релиз сезона целиком с небольшим лагом | «Зайчик»: волна интереса на каждый эпизод (5,6 → >20 тыс. одновременных игроков на 5-м эпизоде); Love, Money, Rock'n'Roll: долгострой убивает ожидания |

**Российские прецеденты**, подтверждающие спрос: «Профессия следователь» (реальные дела, консультант —
бывший следователь; постмортем на DTF обязателен к прочтению), «1997» (детектив в провинциальных
90-х, 91 % положительных), «Бесконечное лето» (постсоветская фактура + музыка = долгий хвост).

**Бренд.** Лицензия на «Криминальную Россию» получена; название и материалы передачи используются
по условиям договора.

## 7. Метрики успеха вертикального среза

- Прохождение ep01 на телефоне (360×640, портрет) без обрезаний текста на 4 языках (es/pt — псевдолокализация).
- Время до `game_ready` на 4G ≤ 8 с; эпизод догружается в фоне.
- Сейв/лоад через Bridge Storage переживает перезагрузку, поворот и interstitial.
- Удержание в песочнице: доля игроков, дошедших до первой мини-игры и до конца эпизода (цели задаёт продюсер после первого трафика).
