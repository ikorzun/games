# Эпизод 1 «Смерть за квартиры» — аутлайн для сценаристов

Первоисточник — русский. Архетип `real_estate_murders`, шаблон блоков — `../architecture/02-narrative-blocks.md` §4.5,
персонажи и правила — `bible.md`, голос рассказчика — `../architecture/07-narrator-styleguide.md`.
Мастер-скелет с id персонажей, переменных, ассетов и мини-игр — `episodes/s1/_drafts/ep01_murylev/_master.json`.
Цель: 50 сцен, 9–11 тыс. слов, 45–55 минут.

## Драматический вопрос
Как квартира стала мотивом, а документы — оружием: следствие ищет не труп, а подпись.

## Персонажи эпизода (id → кто)
`sledak` Андрей Громов (игрок) · `oper` Виктор Сайко · `expert` Нина Левина · `boss` Валентин Павлович, начальник следственного отдела ·
`murashov` Сергей Мурашов (бывший журналист, «риелтор») · `accomplice` Дмитрий Шмелёв «Шмель», подручный · `notary` нотариус Ковригин ·
`zoya` Зоя Павловна (жертва) · `neighbor` Галина (соседка) · `buyer` Лапин (покупатель) · `lapin_wife` Ирина Лапина · `clerk` Раиса Львовна, архив БТИ ·
`sledak_old` Громов в 2004 году.

## Переменные
Эпизодные: `docs_first`, `found_photo`, `docs_flaw`, `wrong_suspect`, `notary_pressed`, `buyer_detained`, `witness_safe`, `found_chain`,
`board_done`, `hasty`, `accomplice_talks`, `confession` ('none'|'partial'|'full'), `route` ('none'|'notary'|'murashov'|'accomplice'),
`kovrigin_broken`, `boss_pressure`, `keys_found`, `galina_trust`, `lapin_wife_met`, `case_strength` (0–8, сила дела).
Глобальные: `trust_oper` (0–5), `oper_wounded`, `boss_favor` (−2…2), `gromov_rep`.
Правило: `case_strength` растёт только через effects в мини-играх и ключевых сценах (см. ниже), никогда «просто так».

## Концовки (ветвление в s48)
- `e_early` «Дело передано»: `case_strength <= 2 && confession == 'none'`.
- `e_variant` «Цена вопроса»: `oper_wounded || buyer_detained || case_strength <= 4`.
- `e_canon` «Дело закрыто»: иначе.

## Правила для сценаристов
- Каждая сцена заканчивается явным переходом (`jump`/`choice`/`branch`/`minigame`/`end`). Переходы — строго по аутлайну.
- Реплика ≤ 180 символов; рассказчик ≤ 3 реплик подряд; выбор не реже чем раз в ~40 реплик; титры `date_stamp` ≤ 32, `location` ≤ 56.
- Рассказчик знает финал, не оценивает, не шутит; персонажи говорят живо (см. библию: Громов — канцелярит, которого стесняется; Сайко — шутит, когда страшно; Левина — коротко и точно).
- Насилие — деталью и последствием. Смерть Зои Павловны не показывается: последний кадр — со спины во дворе.
- Используй только объявленные id (cast, backgrounds, sprites+expressions, music, sfx, ambient, cg, documents, minigames, archive_items). Нужен новый ассет — запиши в `assets_needed`, не выдумывай id в сценах.
- Ключи локализации: `ep01.<scene_id>.l001…` для реплик по порядку, `ep01.<scene_id>.cap` для титров, `ep01.<scene_id>.<choice_id>.prompt` и `.<option_id>` для выборов.
