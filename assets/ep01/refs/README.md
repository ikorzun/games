# Референсы-кропы для генерации кадров покрытия

Кропы принятых кадров, которые планировщик (`tools/shot_plan.py`, `REF_SHOTS` со значением `media:<id>`)
подаёт первым референсом вместо общего плана: модель копирует крупность референса, поэтому для средних планов
нового сета нужен референс средней крупности. Загрузка в Higgsfield идёт по публичному URL файла из этого
каталога (`media_import_url`), потому что прямая загрузка байтов из песочницы закрыта.

| Файл | Из кадра | Для чего |
|---|---|---|
| `apartment_zoya_medium.jpg` | `shots/apartment_zoya/wide_1.webp`, кроп по пояс (Мурашов спиной, Зоя у серванта) | средние планы и ракурсы сета apartment_zoya |
| `notary_medium.jpg` | `shots/notary/wide_1.webp`, кроп по пояс (нотариус за столом, следователь с папкой) | средние планы и ракурсы сета notary |
