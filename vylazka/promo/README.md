## Обложку делает партнёр (21.11, ночь)

Слова партнёра: 21:26 — «Обложку нужно сделать в рамках игровых постеров, нужна и обложка 16:9 и иконка 1:1»; 22:34 — «Нужен другой

22:44 — «обложку сам сделаю, пока все скука». Пробы основной модели (постер с рогатым черепом песчаного зала; название в луче фонаря
с фигурой из точек у края света, без названия, вертикальная, иконки) партнёр видел в чате; в репозиторий они не вошли.

**Что известно о CTR обложки** — `docs/vylazka/_research/cover_ctr.md` (первоисточники площадок из сессии не открылись, цитаты — из
пересказов поиска): площадки расходятся по названию на обложке — CrazyGames просит название, Poki — миниатюры без текста (по их тестам
игроки выбирают такие); если название есть, оно должно читаться на самой мелкой плитке; у хорроров главная ошибка — «слишком темно»,
нужна одна точка фокуса и светлое на тёмном; лицо в миниатюре поднимает CTR (данные слабые); иконка — один предмет без текста. В требованиях
Playgama (Game Requirements, прочитаны через MCP площадки) правил для обложек нет — другие страницы вики из сессии не открылись; про
содержимое там есть 4.1 (без насилия, войны, политики) и 4.3 (целиком сгенерированное проседает вдвое).
