# Геймплейное видео Untitled Session

Партнёр 21.11, 19:24: «Видео запиши только после всех изменений и с лучшими моментами, давящей атмосферой страха и потерянности».
Видео не сгенерировано, а записано из самой игры: настоящая сборка в Chromium, кадр за кадром. Это нужно и для честности перед
игроком, и для правил площадки: Playgama пишет, что целиком сгенерированное проседает по метрикам вдвое.

Как переснять после новых изменений (из папки `vylazka/`):

```bash
npm run build                                   # или сборка в отдельную папку: npx vite build --outDir dist-rec, затем DIST=dist-rec
node tools/video/record.mjs record s1           # сцены можно писать параллельно, по одной на процесс: s1, s3, s4b, s5, s6
python3 -I tools/video/hold_card.py e2e/out/gameplay/s6 e2e/out/gameplay/s6_held 159 156
python3 -I tools/video/title_card.py e2e/out/gameplay/title <DMMono-300.ttf>
python3 -I tools/video/assemble.py tools/video/edit.json <выход.mp4>
```

- **Запись** (`record.mjs`): страница с `?q=med`, шаги симуляции и снимок после них (30 к/с), интерфейс скрыт, кроме рамки камеры (REC,
  номер, время). Программная отрисовка в контейнере медленная — около 12 кадров в минуту на процесс; сцена в 10–12 с — 20–30 минут.
  `__vz.look()` в игре прибавляет поворот к текущему, как мышь: панорамы считаются приращением от нынешнего взгляда (`aimAt`).
- **Сцены**: s1 — темнота, фонарь зажигается и место собирается из точек, путь по коридору, тишина, в дальнем проёме разгорается
  Осыпь; s4b — песчаный зал монтажом (от проёма, рёбра, под сводом, наезд на череп; точки — те же, что у кадров для обложек); s3 —
  белая комната, шаг к цепи и перекрут; s5 — свет гаснет, к тебе идёт рой точек, поимка; s6 — место рассыпается, лимбо и обрывок
  метаслоя «are you awake?».
- **Карточка обрывка** (`hold_card.py`): DOM живёт по настоящему времени страницы, а запись идёт по кадру за несколько секунд — в ролике
  она мелькнула бы в паре кадров. Скрипт держит её 4,5 с и медленно наезжает на неё.
- **Звук** (`assemble.py`, `edit.json`): только звуки игры из `public/audio` (ElevenLabs и записи партнёра) — фон места, шаги, щелчок
  фонаря, тишина перед явлением, сбор и распад Осыпи, цепь и белая вспышка, поимка и помехи, слой «явь» в лимбо. Номера кадров в
  `edit.json` — от начала куска.
- **Не вошло**: «тёмный урок» (контур фигуры сквозь стены) — в записи контура не видно, нужна своя постановка камеры.
