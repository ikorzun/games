# Untitled Session — исследование от первого лица

Вторая игра репозитория (папка пакета пока прежняя — `vylazka/`), отдельный пакет: по сборке
от новеллы (`runtime/`) не зависит. Игрок с одним фонарём ходит по заброшенному убежищу, в которое
вросли домашние комнаты, и ищет вещи из воспоминаний; место время от времени рассыпается и выбрасывает
в другое. Кнопки действия нет: игрок ходит, смотрит и светит. Язык по умолчанию — английский.
Кроме убежища есть ещё два мира — офис и «жёлтые комнаты»; место выбирается на заставке.
Движок — three.js (WebGL2), мир собирается кодом. Замысел — `docs/vylazka/untitled_session.md`,
числа и устройство — `docs/vylazka/design.md`, план восьми вылазок — `docs/vylazka/sorties.md`,
откуда взяты готовые модели — `docs/vylazka/assets.md`, как делаются объекты (код, модели, сканы,
картинки) — `docs/vylazka/modeling.md`. Что дальше и какие решения ждут партнёра —
`docs/vylazka/plan.md`; все его идеи с разбором — `docs/vylazka/ideas.md`; структура кода и путь
роста — `docs/vylazka/architecture.md`; выбор стека — `docs/vylazka/stack.md`; грибница, которая
растёт по точкам места (пока вывод и набросок) — `docs/vylazka/growth.md`; петля, стирание, ступени вещей и распад в пыль — `docs/vylazka/decay.md`; связка вылазок и сюжет — `docs/vylazka/story.md`; давление помимо Осыпи (первая версия в игре: пол рассыпается, потолок опускается; отладка — `__vz.pressure()`, параметр адреса `press`), случайное попадание в воспоминание и перемешивание мест (проработка) — `docs/vylazka/pressure.md`; сводка источников о снах и памяти — `docs/vylazka/dreams.md`; ощущения по местам, определение «полной локации» и что осталось до четырёх — `docs/vylazka/sensations.md`; мета-слой «путь, который становится вещью» (предложение, в игре нет) — `docs/vylazka/meta.md`; приёмы кино по деконструкции пространства и что из них взять — `docs/vylazka/cinema.md`; дешёвые визуальные трюки three.js: что есть, что взять, что не брать, птицы — `docs/vylazka/tricks.md`; четвёртое место, зал ожидания (время идёт вместе с игроком; стоя он видит снимок) — `docs/vylazka/station.md`. Графика смешанная: болванки из кода, готовые модели,
плоские вещи и картинки на экранах (`assets/screens/`, запросы — `docs/vylazka/screens.md`). Плакаты на стенах убежища — настоящие листы-картинки
(`assets/posters/`, там же README; запросы, по которым они сделаны, — `docs/vylazka/posters.md`). Старые
портреты, деньги, акции и карта — вырезки из фотографий партнёра (`assets/papers/`, там же опись: что на
листах, чего на них нет и как пересобрать); правила «что в 3D, а что плоским» — `docs/vylazka/modeling.md`, §7.

**Последнее (15.11, ночь):** бумага и чемоданы из присланных фотографий. Стена лиц, портреты в рамах и
лист над кроватью в убежище (лица вблизи расплываются — «the faces did not save»), деньги и акции в
архиве и в офисе, один портрет в жёлтых комнатах, стена чемоданов и карта в зале ожидания. Устройство —
`docs/vylazka/design.md`, §18.

**Последнее (15.11, вечер):** эффекты из `docs/vylazka/tricks.md` (тень переплёта по формуле, свечение
на просвет, ветер, тени-пятна, блики ряби, стекло крыши, ложная комната за окошком кассы, разрыв кадра,
объём для точек, конус луча на низком качестве, шестиугольная укладка фактуры, мох слоями), птицы
(`src/systems/birds.ts`; отладка — `__vz.birds()`) и полярность Осыпи: в светлом воспоминании она
темнота, в тёмном — свет (`docs/vylazka/entity.md`). Числа — `docs/vylazka/design.md`, §17.

**Состояние:** ядро (сессия, скачки, вещи), три карманных пространства (белое нигде, луг, кукольный
домик), особые помещения, кинескоп и рендер мира точками (как 3D-скан: под лучом фонаря мелкие мягкие
точки сходятся в поверхность, вокруг висят россыпью и разлетаются, когда луч уходит) сделаны. Сделаны
эхо (без света фонаря шаг показывает линии места; стоящий в темноте не видит ничего), призрак Осыпи
из-за спины и два мира со своим светом —
офис (фонаря нет; панели с датчиками, которые теряют неподвижного) и жёлтые комнаты (темно и чисто,
светит только фонарь; на этаж два экрана). Всё иллюзорно: чего коснулся игрок — растворяется и
возвращается, когда свет погас и зажёгся, — на ступень хуже (картонка, проекция, кружево, нет). Каждое место — воспоминание, которое с каждым кругом стёрто сильнее (`decay.md`): тают вещи, потолок, стены; прорастают берёзы без листьев; у входа растёт гора; из тронутого растёт Осыпь, и вокруг неё — грибы. Есть бумажные цветы, наклейки и завал. Сделаны плоские вещи:
картонки (мебель, которая оказалась листом), проекции (комната из света поперёк коридора — луч
фонаря её смывает) и выставочные экраны с картинками природы и поп-культуры. Звук есть: 53 звука, 87 файлов, около 410 с — сгенерированы в ElevenLabs, кроме одного (запись партнёра), с шиной голосов — следами людей (`audio/README.md`); послушать и оценить должен партнёр. Частота кадров на телефоне не измерена. Публикация на
площадке отложена до оценки партнёром.

## Команды

```bash
cd vylazka && npm install
npm run dev                # dev-сервер, http://localhost:5175
npm run typecheck && npm test
npm run build              # dist/ + проверка архива (scripts/check_dist.mjs)
npm run build:playgama     # dist-playgama/ с Playgama Bridge SDK; архив, события, чеклист — docs/vylazka/playgama.md
npm run build:single       # dist/ одной страницей (dist-single/untitled_session.html): код, шрифты и плакаты вшиты
npm run smoke              # смоук сборки в Chromium (программный WebGL)
npm run smoke -- --dist dist-playgama
npm run smoke -- --shell   # в chromium-headless-shell: тот же браузер, что на CI
npm run smoke:matrix       # + раскладка на 6 размерах экрана × ru/en, скриншоты в e2e/out/
node e2e/shots.mjs         # скриншоты ракурсов тестового коридора в e2e/out/shots/ — смотреть картинку глазами
node e2e/shots_gen.mjs     # скриншоты сгенерированного бункера: по кадру на примету и на коридор яруса
node e2e/shots_props.mjs   # скриншоты витрины реквизита: по кадру на предмет из реестра PROPS
node e2e/shots_pocket.mjs --kind meadow   # четыре вида карманного пространства (void, meadow, dollhouse); --q, --walk N
node e2e/smoke.mjs --only worlds           # один сценарий смоука: play, gen, worlds, flats, session, pockets, fear, audio, frame, touch, bridge, matrix

# Ролик о сути игры (15 секунд). Запускается вручную, в сборку и CI не входит; нужны Pillow и ffmpeg.
node e2e/trailer.mjs scout                                   # кадры с точек съёмки в e2e/out/scout/: выбрать вещь и ракурсы
node e2e/trailer.mjs record && python3 scripts/trailer.py    # кадры ролика → e2e/out/untitled_session_15s.mp4

# Готовые модели (itch.io, CC0). Запускается вручную, в сборку и CI не входит; нужен Pillow.

python3 -I scripts/import_models.py <каталог распакованного набора>      # → src/world/models_data.ts
python3 -I scripts/papers_import.py <папка со снимками> --pylib <папка с OpenCV ниже 5> --check лист.jpg   # → assets/papers/*.webp (см. там README)
```

Браузер для смоука: переменная `CHROMIUM_PATH`, иначе `/opt/pw-browsers/chromium`, иначе
`npx playwright-core install chromium`.

Браузеров два, и перед отправкой смоук стоит прогнать в обоих. Локально по умолчанию идёт полный
Chromium — он ведёт себя как браузер игрока. CI берёт `chromium-headless-shell` (ключ `--shell`),
а у того захват мыши ненастоящий: курсор стоит в точке (0, 0), каждое движение приходит парой
«+координата, −координата», нажатие кнопки — одиночным рывком. Проверка, зелёная в одном браузере,
может упасть в другом; какой браузер гонял тест, написано в первой строке лога.

Ещё одна особенность `chromium-headless-shell`: пока мышь захвачена, сам браузер без остановки шлёт
странице синтетические «движения» — десятки тысяч событий в секунду. Лёгкая страница их разбирает,
а на полном уровне они копятся: за секунды браузер и страница набирают гигабайты памяти, кадры почти
перестают идти, длинный сценарий заканчивается падением страницы («Target crashed»). В полном Chromium
и в настоящих браузерах этого нет. Поэтому смоук захватывает мышь по-настоящему только там, где
проверяется сама мышь, и только на лёгкой странице (низкое качество): вторая страница сценария
«Игра на ПК» — тряска, пауза, потеря и возврат захвата — и первая половина «Звука». Картинку
на высоком качестве тот же сценарий проверяет на отдельной странице с заглушкой. Остальным страницам
смоук тоже подставляет заглушку захвата (`FAKE_LOCK` в `e2e/smoke.mjs`): игра считает мышь
захваченной, браузер её не трогает.

Чтение пикселей кадра (`__vz.probe()`, `__vz.probeColor()`) на программном рендере медленное: каждый
вызов ждёт, пока кадр дорисуется целиком. Поэтому частоту и порядок событий проверки считают по
состоянию игры (`__vz.state()`), а кадром подтверждают картинку — несколькими чтениями, не десятками.
Сама игра пикселей не читает.

Проверки не должны зависеть от скорости машины. Часть событий игры живёт в настоящем времени: вспышка
воспоминания горит 5,2 с, сообщения — несколько секунд, графический контекст возвращается, когда
пересоберутся шейдеры. Такое читается тем же обращением к странице, которым вызывается, или ожидается
по условию (`waitForFunction`), а не по сроку: CI уже падал на проверке, которая читала вспышку через
десяток обращений после её появления. Запас по времени проверяется прогоном на двух ядрах из четырёх:
`taskset -c 0,1 node e2e/smoke.mjs --shell --matrix --no-shots`.

И от случая проверки зависеть не должны. До заморозки (`freeze(true)`) игра успевает прожить несколько
кадров в настоящем времени, и сколько именно — зависит от машины; дальше случайные числа игры идут
уже по-другому. Поэтому то, что игра выбирает случайно (срок карманного пространства — 46–60 с),
проверка читает из состояния (`pocketInfo.stay`), а не угадывает по общему пределу.

## Управление

| | ПК | Телефон |
|---|---|---|
| Идти | WASD или стрелки | коснуться и отпустить — шаг вперёд; держать палец на месте — идти вперёд, пока держишь; в левой половине экрана повести пальцем — стик (в любую сторону) |
| Вести луч | мышь (если страница не даёт её захватить — мышь с зажатой кнопкой) | вести пальцем в правой половине экрана; если палец уже идёт удержанием, он ведёт луч, а ходьба продолжается |
| Бежать | Shift | стик до упора |
| Фонарь | F или левая кнопка мыши (одно нажатие — одно переключение; без захвата мыши — короткий клик на месте) | кнопка справа внизу: короткий тап — включить или погасить; держать на ней палец — фонарь заряжается (кольцо вокруг кнопки больше), на полном — вспышка и свет |
| Трясти заглохший фонарь | резко водить мышью из стороны в сторону; запасной способ — стучать F | держать палец на кнопке фонаря (зарядка оживляет и его; тап заглохший не оживляет); тряска самим телефоном — усиление, если датчик доступен |
| Пауза | P (Esc игрой не используется) | кнопка слева вверху |
| Обвязка телефона | — | свайп от края экрана и щипок игре не отдаются; звук играет и в беззвучном режиме iPhone; пока идёт игра, экран не гаснет (`design.md` §23) |
| Звук | M или кнопка «Звук» на заставке и на паузе | кнопка «Звук» там же |

Кнопки действия нет: клавиш E, R, Tab и кнопок «взять» и «цели» больше нет. Вещь «вспоминают»,
подержав её в луче.

## Параметры адреса

| Параметр | Что делает |
|---|---|
| `?seed=N` | сид убежища (по умолчанию берётся из профиля игрока) |
| `?world=shelter\|office\|yellow\|station` | мир вылазки: убежище, офис, жёлтые комнаты, зал ожидания (по умолчанию — выбранный на заставке кнопкой «Место») |
| `?rank=1\|2\|3` | ранг объекта: 1 — два яруса, 2 и 3 — три (по умолчанию — по числу успешных вылазок) |
| `?level=pocket_void\|pocket_meadow\|pocket_dollhouse` | просмотр карманного пространства: белое нигде, луг, кукольный домик |
| `?level=test` | вместо генератора — коридор технического среза, собранный руками |
| `?level=show` | витрина реквизита: предметы реестра `PROPS` в ряд у стены; `&props=a,b,c` — только названные; `&flat=1` — напольные предметы стоят картонками (сравнить плоский с настоящим) |
| `?stage=0…4` или `#stage0…#stage4` в конце ссылки | ступень погружения (design.md §24): 0 — холодный старт и одно правило, 4 — всё сразу; без параметра — по числу законченных сессий, в проверках (`fail=`, `level=`, `seed=`) — 4 |
| `?q=low\|med\|high\|ultra` | качество (иначе: телефон — среднее, ПК — высокое; сильный ПК по замеру при запуске получает «ультра» — высокое с зерном и точками вдвое мельче; через 10 с игры понижается само, если кадров мало) |
| `?wear=0.56` | посмотреть место на любом круге петли: стёртость от 0 до 1 (таблица кругов — `docs/vylazka/decay.md`, §4) |
| `#lap5` (в конце адреса) | то же по номеру круга, 1–8: для страницы по ссылке, у адреса которой нет параметров |
| `?scenes=1` или `#scenes` | прототип «сна из сцен» (`docs/vylazka/pressure.md`, §4.6): сессия — три сцены из разных мест, в каждой одна вещь цепочки своего места; вспомнил — свет гаснет, и вокруг другое место; после третьей — лимбо |
| `?lang=ru\|en` | язык (по умолчанию английский; русский включается и в настройках) |
| `?touch=1\|0` | принудительно включить или выключить тач-управление |
| `?fps=1` | счётчик кадров, размер буфера, вызовы отрисовки и треугольники под временем записи |
| `?fail=N` | первый отказ фонаря через N секунд (`0` — режим проверок: фонарь глохнет только по команде проверки `__vz.fail()` — ни принудительного, ни случайных отказов, и батарейка не садится; по умолчанию 40, в тестовом коридоре 12) |
| `?pseudo=1` | псевдолокализация: строки длиннее на 35 % |
| `?autostart=1` | без стартового экрана |
| `?audio=папка` | взять весь набор звуков из папки рядом с игрой, а не из сборки (послушать новые клипы без пересборки) |

```
  systems/                     flashlight (отказы, оживление тряской; батарейка садится, севшая отлёживается),
                               session (воспоминания, паника, среда, обвалы),
                               things (вещи под взглядом: уменьшаются, рассыпаются, растут;
                               от касания растворяются и возвращаются),
                               illusions (всё иллюзорно: предмет обстановки стоит → растворяется
                               → нет → собирается; каким вернётся — решает сид),
                               jumps (когда и куда выбрасывает: скачки),
                               echo (волны эха и мера «за спиной» для призрака),
                               cell_lights (свет потолочных панелей по клеткам: датчики, которые
                               теряют неподвижного),
                               director (когда и чем пугать), anomalies (лестница, комната)
  swarm/                       ai (поведение роя на графе уровня), body (черви и фигура)
  audio/                       engine (WebAudio: банк, разовые звуки и петли, панорама),
                               game_audio (какой звук на какое событие и состояние игры)
  core/save.ts                 профиль (архив вспомненного, настройки): пакетная запись по событиям

```

- **Один материал на весь мир.** Атлас 8×4 matcap-шаров запекается на CPU при старте
  (`render/matcap_atlas.ts`), номер материала лежит в вершине. Помещение — один чанк и один вызов
  отрисовки; длинные коридоры режутся блоками 4×4 клетки. В сгенерированном бункере кадр — 20–50
  вызовов и 60–110 тысяч треугольников вместе с проходом тени.
- **Поверхность = шар + фактура + запустение.** Фактуры — стопка из 17 тайловых слоёв
  (`render/detail.ts`), рельеф наклоняет нормаль по экранным производным. Запустение — одна карта
  (`render/grime.ts`), по которой краска облезает чешуйками, металл ржавеет, бетон сыреет. Всё
  рисуется кодом, готовых картинок в сборке нет. Подробно — раздел 6 документа с правилами.
- **Надписи** — атлас на canvas (`render/signs_atlas.ts`) по раскладке из `world/signs.ts`:
  трафареты, таблички, плакаты ГО, шкалы. Лист со знаком — обычный четырёхугольник мира с uv в атлас.
- **Окружение пространств**: у убежища и карманных пространств свой `Env` — рассеянный свет, цвет
  дали, туман, множитель света фонаря (`world/pockets.ts`). Остальное — `design.md`, разделы 6 и 7.
- **Распад и красная сетка**: вершинный шейдер рассыпает мир или вещь, отдельный проход рисует
  красный каркас; кинескоп и срывы кадра — в пост-проходе (`render/shaders.ts`).
- **Дымка в луче** — отдельный маленький проход по глубине кадра (`HAZE_FRAG`).
- **Эхо** — ещё один полноэкранный проход по той же глубине (`ECHO_FRAG`): до шести волн, у каждой
  точка в мире и радиус; кромки предметов берутся из второй разности глубины. Рисуется в свой слой
  и только пока жива хоть одна волна.
- **Миры.** Генератор один; мир (`WorldKind`) задаёт набор помещений, проходы, стиль отделки,
  обстановку, окружение и набор воспоминаний. В офисе и жёлтых комнатах свет даёт место: уровень
  света каждой клетки лежит в текстуре 16×16, шейдер мира умножает на него рассеянный свет
  (`systems/cell_lights.ts`, `design.md`, раздел 14).
- **Плоские вещи.** Картонка — предмет, сплющенный на плоскость центральной проекцией из одной
  точки (`world/flat.ts`): оттуда он выглядит объёмным, сбоку это лист; идёт в обычную сетку
  помещения. Проекции и картинки экранов — свет, а не вещество: отдельная сетка куска
  (`LevelChunk.slides`), тот же шейдер мира с веткой `SLIDE`, без тени и без точек. Проекцию свет
  смывает (зерном, до дыры), экран — нет. Картинки экранов — свой атлас (`uScreens`), первые две
  клетки рисует код: экран светится и без файлов.
- **Готовые модели** лежат в `src/world/models_data.ts` в формате игры (позиции, нормали, цвет
  вершины — квантованные, base64). Файл генерируется `scripts/import_models.py`, руками не правится.
- **Рой** — один вызов отрисовки: шаблон червя (9 колец × 5 граней) размножен инстансами, изгиб тела
  считает вершинный шейдер; прозрачность — экранным дизерингом, без сортировки. В момент поимки рой
  смыкается в метре от камеры, а экран закрывает срыв сигнала: сотня червей на объективе стоила бы кадров.
- **Звук** — только файлы, по списку `audio/manifest.json`; синтеза в коде нет. Разовые звуки идут
  из событий шага, петли пересчитываются каждый кадр из состояния игры. Игра запрашивает только те файлы, что лежат в сборке; шина `voices` — следы людей (разговор за стеной, шёпот, редкие смех и оклики); подробности — `audio/README.md` и раздел 13 документа с правилами.
- **Отсечение.** Чужой ярус рисуется только с лестницы и в 16 м от её площадок; дальше 30 м чанки
  не рисуются — свет фонаря туда не достаёт.
- **Генератор** считает только целочисленным ГСЧ: один сид даёт один уровень на любом устройстве.
  План и сборка уровня третьего ранга занимают десятки миллисекунд и пока идут в основном потоке.
- **Свет**: `ambient (альбедо × AO) + фонарь × matcap`. Matcap берётся по направлению на фонарь
  и входит только в слагаемое фонаря, поэтому при погасшем фонаре мир не подсвечен «от камеры».
- **Тень фонаря** — ручной depth-pass из руки. Фонарь держат у пояса (0,27 м правее и 0,42 м ниже
  камеры): тени уходят вверх по стенам и заметно смещены. На низком качестве выключена.
- **Бодикам** — один пост-проход: бочкообразная дисторсия, хроматическая аберрация, усиление
  сенсора с шумом, мягкий клиппинг, виньетка. Усиление считается аналитически по лучам фонаря
  (`render/exposure.ts`), без чтения пикселей.
- **Разрешение фиксированное**: 640×360, 960×540 или 1280×720 по качеству; canvas растягивается CSS.
  Четвёртая ступень, «ультра», — буфер до 2560×1440 (не больше экрана): то же высокое качество, но
  зерно и точки вдвое мельче (`docs/vylazka/design.md`, «Качество»).
- **Симуляция** — фиксированный шаг 1/60 с; поворот луча применяется сразу, без ожидания шага.
- **Контроллер** — цилиндр против осевых коробок; препятствия ниже 0,36 м перешагиваются, поэтому
  лестницы собираются из ступенек-коробок.

## Отладочный API `window.__vz`

Ставится и в боевой сборке: смоук гоняет именно её. Основное: `state()`, `freeze(on)`,
`step(n, input)`, `tick(n)` (обороты цикла с настоящим вводом), `teleport(x, y, z, yaw, pitch)`,
`fail()`, `shake(level, seconds)`, `quality(q)`, `info()` (вызовы отрисовки, треугольники, размер
буфера; про облако точек — `points`: сколько точек отдано видеокарте, `clouds`: у скольких сеток есть
облака, `cells`: сколько клеток с точками живо), `cloudUsage()` (сколько из отданных точек шейдер
показывает; считает перебором, медленно), `probe()` (яркость кадра сеткой 32×18),
`shadows(on)`, `scan(on)` (облако точек вкл/выкл), `geometryAudit()` (у каждой сетки на сценах хватает каждого канала на все вершины — проверка, которую делает Safari; пусто — в порядке), `loseContext(ms)`, `lang(code)`, `level()` (помещения и приметы), `gotoLandmark(id)` (например, `grove` — берёзы в отделе офиса),
`gotoRoom(id)`, `hazards()`, `swarm('release'|'appear'|'sleep', hops)`, `phase(n)`, `anomalies()`, `calm(on)` (без роя и пугалок),
`audio()` (что загружено, что игра просила сыграть и что прозвучало, какие петли идут), `mute(on)`.

Добавились (интерфейс `VzDebugApi` в `src/debug/debug.ts`): `look(yaw, pitch)`, `toggleLight()`,
`start()`, `pause(on)`, `render()`, `things()` (вещи сна и их состояние), `gotoThing(id)`, `sees(id)`
(почему вещь видна или нет), `memory()` (искомое воспоминание), `reveal()` (поторопить следующее), `memLight(id | null)` (свет памяти у любой вещи — `docs/vylazka/design.md` §21), `charge(x?)` (заряд батарейки фонаря 0..1: задать и прочитать — кольцо заряда вокруг значка фонаря), `spawnThing(kind, fate, distance?, facing?)` (поставить вещь перед камерой; `facing` — лицом к игроку),
`gotoMemory()`, `gotoPocket('exit' | 'focus', distance?)` (в карманном пространстве встать перед красным проёмом выхода или перед макетом в домике и посмотреть на него), `jump(to, style)` (начать скачок), `gotoFx(fx)` (встать в помещение с особенностью
`strobe`, `dark`, `wire`, `thin`), `finish()` (считать всё вспомненным), `calmFlash(on)` (мягкие
вспышки), `probeColor()` (средний цвет кадра и доля красных точек), `missingKeys()`, `showcase()`,
`sheets()` (какие листы-плакаты загружены), `sheetMarks()` (где они висят), `gotoSheet(i, distance?)` (встать
перед листом), `sheetContrast(id)` (есть ли в клетке листа рисунок: у пустого листа около 10, у плаката — десятки).
В `state()` есть `dark` — `{ for, shifts }`: сколько секунд фонарь не светит и сколько вещей темнота
уже поменяла. Там же `pocketInfo` — `{ age, stay, done, fade, exit, focus, blanks }`: сколько прошло и
сколько отпущено в карманном пространстве, сделало ли оно своё дело, насколько редеет (1 → 0,2), где
выход и главный предмет (макет), какие вещи — белые болванки; вне пространства `null`. Ещё в `state()`:
`world` (мир вылазки), `echo` (живые волны: род, место, радиус, сила), `ghost` (насколько виден призрак
Осыпи, 0..1), `ambientLocal` (свет клетки под игроком), `lights` — `{ lit, total }` (сколько клеток
освещено; в убежище `null`), `jump.dest` (куда ведёт идущий скачок; `start` — в начало вылазки).
`level()` отдаёт ещё `world`, `spawn` и `flats` (плоские вещи: род и что изображено). Плоские вещи:
`flats()` (картонки, проекции, экраны: где стоят и куда смотрят), `gotoFlat(i, distance?, side?)`
(встать перед вещью; отрицательное расстояние — с изнанки), `slides(on)` (скрыть проекции и
картинки экранов, чтобы сравнить кадр), `screens()` (какие картинки экранов загружены), `papers()` (какие слои бумаги загружены). Экран-проём —
это экран с картинкой `meadow` и объект `display_door`. Карточка от руки: `notes()` (где висит),
`gotoNote(i, distance?)` (встать перед ней). В `info()` —
`slides`: у скольких кусков уровня есть сетка света. Иллюзорные вещи: `objects()` (предметы
обстановки: имя, место, габариты, преграда, картонка ли, состояние `here`/`going`/`gone`/`coming`/`left`
и доля распада), `gotoObject(id, distance?)` (встать перед предметом лицом к нему); в `state()` —
`illusions` (`{ gone, back }`: сколько вещей растворилось и сколько вернулось), `hasLight` (есть ли
здесь фонарь: в офисе нет), `stillFor` (сколько секунд игрок неподвижен). Строка-вспышка
горит несколько секунд настоящего времени: читайте её тем же `page.evaluate`, которым вызвали событие.
Убраны `goals()`, `items()`, `gotoGoal(i)`, `gotoItem(id)`, `gotoExit()`.

## Проверено и не проверено

- Проверено в Chromium на программном WebGL: логика (список проверок — вывод `npm test` и `npm run smoke`), вёрстка на шести размерах экрана, сборка
  с настоящим Bridge SDK на его mock-платформе, потеря и восстановление графического контекста.
- **Не проверено: частота кадров на телефоне**, в том числе новых эффектов (кинескоп, распад, красная
  сетка, строб, эхо, свет по клеткам, проекции и экраны). В тестовом окружении нет видеокарты; посмотреть надо на реальном устройстве.
- **Звук не прослушан:** набор сгенерирован, но на слух его проверяет партнёр (модель услышать не может); все клипы раскодируются в память сразу (десятки мегабайт) — на телефоне стоит грузить по миру.
- Захват мыши внутри iframe проверен автотестом для худшего случая — песочница без
  `allow-pointer-lock` и без хранилища: игра идёт, луч ведётся мышью с зажатой кнопкой. Как
  встраивает игру конкретный портал, видно только на площадке.
- Акселерометр внутри iframe порталов не проверялся: в автотесте его нет.
- **Safari строже Chrome к сеткам.** Если данных какого-то вершинного канала меньше, чем вершин, Safari не
  рисует сетку целиком, а Chrome подставляет нули — в Chromium такую ошибку не видно (так на iPhone пропадали
  зал ожидания и половина бункера, `docs/vylazka/design.md`, §20). Сторожат тест `tests/mesh_channels.test.ts`
  и `__vz.geometryAudit()` в смоуке. Проверка на самом телефоне — `#diag` в адресе или долгое нажатие на
  «качество» в паузе.

### Каталог мебели (`tools/mebel/`)

Страница для партнёра: каждая вещь реестра, собранная тем же кодом, что в игре, объёмно и рядом с
ростом человека; где и сколько раз она стоит на уровнях; отметки «оставить / сделать реальнее /
заменить / убрать» с заметкой — в общей базе страницы (коллекция `verdicts`), откуда их читает
основная модель. Собрать: `node tools/mebel/build.mjs <out.html>`; кнопка «посмотреть в игре» открывает
вещь в витрине игры по адресу `#show-<имя-через-дефисы>`.
