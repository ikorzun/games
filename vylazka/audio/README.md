# Звуки «Вылазки»

`manifest.json` — источник правды: id звука, шина, число вариантов, длительность, громкость,
`prompt` (инструкция генеративной модели, по-английски) и `ru` (что это и где звучит).
Какой звук когда играет — `../src/audio/game_audio.ts` и `docs/vylazka/design.md`, раздел 13.

Файлы лежат в `../public/audio/` как `<id>_<n>.mp3`, `n` от 1 до `variants`; Vite копирует папку
в сборку (`dist/audio/`). Сборка запоминает, какие файлы там лежат, и игра запрашивает только их.

Сгенерированные клипы руками туда не кладутся — их приводит к общему виду скрипт (нужен ffmpeg):

```bash
node scripts/audio_import.mjs <папка с исходниками>            # весь набор; нет хотя бы одного — ошибка
node scripts/audio_import.mjs <папка> --only drip,scare_bang   # перезаписать отдельные звуки
node scripts/audio_import.mjs <папка> --dry                    # только показать, что получится
```

Исходники называются так же: `<id>_<n>.wav` (или mp3, ogg, m4a, flac). Скрипт обрезает тишину
по краям, укорачивает разовые звуки до длины из манифеста, приводит пик к −2 дБ (баланс между
звуками задаёт поле `volume`, а не громкость файла), сводит клипы в моно (музыка остаётся стерео)
и кодирует в mp3 44,1 кГц. Петли зацикливать в файле не обязательно: стык делает игра (`xfade`).

Звука, синтезированного в коде, в игре нет: площадка такой не принимает. Пока файлов нет, игра
молчит, а `scripts/check_dist.mjs` предупреждает об этом. Если набор неполный — сборка останавливается:
выпускать игру с половиной звуков нельзя. `VZ_REQUIRE_AUDIO=1` делает ошибкой и полное отсутствие файлов.

Послушать новые клипы без пересборки: положить их в любую папку рядом с игрой и открыть игру с
`?audio=<папка>` — тогда весь набор берётся оттуда. Состояние звука видно в консоли: `__vz.audio()`.
