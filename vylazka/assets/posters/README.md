# Плакаты и план убежища

Листы, которые висят на стенах убежища: девять плакатов гражданской обороны и план убежища. Это
картинки, а не рисунки кодом: игра вклеивает их в атлас надписей (`src/render/signs_atlas.ts`) и
старит — сгибы, пожелтевшие края, пятна, ржавчина от кнопок.

| Файл | Что на листе |
|---|---|
| `poster_alarm.webp` | По сигналу «Воздушная тревога» |
| `poster_mask.webp` | Умей пользоваться противогазом |
| `poster_shelter.webp` | Правила поведения в убежище |
| `poster_aid.webp` | Первая медицинская помощь |
| `poster_signals.webp` | Сигналы гражданской обороны |
| `poster_protect.webp` | Средства индивидуальной защиты |
| `poster_nuclear.webp` | Ядерный взрыв. Поражающие факторы |
| `poster_refuge.webp` | Убежище — надежная защита |
| `poster_dose.webp` | Дозиметрический контроль |
| `scheme.webp` | План убежища (лист на боку) |

- `*.webp` в этой папке — файлы для игры: 512×768 (план — 768×512), качество 82, всего около 620 КБ.
  Сборка кладёт их отдельными файлами `assets/<id>-<хеш>.webp`; `scripts/check_dist.mjs` следит, чтобы
  ни один не потерялся.
- `master/*.webp` — те же листы в полном размере (1024×1536, качество 92). В сборку не попадают; из них
  файлы для игры собираются заново.

## Откуда они

Листы нарисованы нейросетью 14 ноября 2026 года по решению владельца: подлинные плакаты ГО 1960–80-х
защищены авторским правом, а эти — новые работы в той же манере, поэтому вопросов с правами нет.
Модель — GPT Image 2 через ElevenLabs (обычное качество, 1K, 2:3; план — 3:2). Все десять листов
приняты с первой попытки, каждая надпись проверена глазами. Запросы, по которым они сделаны, —
`docs/vylazka/posters.md`.

## Как добавить или заменить лист

1. Положить полный размер в `master/<id>.webp`, файл для игры — в `<id>.webp` (пропорция 2:3 или 3:2).
2. Новый лист вписать в `src/world/signs.ts` (`sheet('<id>', …)` и список `POSTERS`).
3. `npm test` (проверяет файлы и размеры) и `npm run build`.
