# Картинки выставочных экранов

То, что светится на больших экранах игры (`src/world/props_screens.ts`): природа, природа не на своём
месте, обрывки поп-культуры. Игра кладёт их в отдельный атлас (`src/render/screen_images.ts`); первые
две клетки атласа — настроечные полосы и «снег» — рисует код, файлов у них нет.

| Файл | Род | Что на картинке |
|---|---|---|
| `roots.webp` | природа | корни дерева в срезе рыжей земли |
| `moss.webp` | природа | поваленный ствол во мху, еловый лес |
| `lichen.webp` | странное | бетонная стена в разноцветном лишайнике и цветах |
| `flooded.webp` | странное | комната, залитая прозрачной водой, кувшинки на полу |
| `birches.webp` | странное | берёзы, проросшие сквозь пол офиса |
| `deer.webp` | странное | косуля на лестничной площадке панельного дома |
| `gameshow.webp` | поп-культура | пустая студия телеигры девяностых |
| `cartoon.webp` | поп-культура | кадр рисованного мультфильма: круглый зверь на холме |
| `meadow.webp` | проём | луг самой игры с точки появления: тропа к дверной раме |
| `books.webp` | витрина | книжный автомат: полки с книгами в странных обложках (не экран — стекло автомата, `props_office.ts`) |

- `*.webp` в этой папке — файлы для игры: 384×640 (3 : 5), качество 82, всего около 480 КБ. Сборка
  кладёт их отдельными файлами `assets/<id>-<хеш>.webp`; `scripts/check_dist.mjs` следит, чтобы ни один
  не потерялся. Не загрузился файл — на экране настроечные полосы: игра от картинок не зависит.
- `master/*.webp` — те же кадры в полном размере (720×1280, качество 90). В сборку не попадают; из них
  файлы для игры собираются заново (срезать поровну сверху и снизу до 3 : 5, уменьшить).

## Откуда они

Восемь картинок сделаны нейросетью 14 ноября 2026 года: GPT Image 2 через ElevenLabs (обычное качество,
1K, 9 : 16), все приняты с первой попытки, 185 кредитов за штуку. 21 ноября они сделаны заново — как снимки
с iPhone 4 (партнёр: «слишком нейронные… словно они сняты на iphone4»): GPT Image 2.6 через ключ OpenAI
партнёра, качество medium. Это новые изображения, а не чужие фотографии или кадры: на них нет людей,
надписей, знаков и узнаваемых героев. Запросы, по которым они сделаны, — `docs/vylazka/screens.md`.

`meadow.webp` — не картинка нейросети, а кадр самой игры: карманное пространство «луг» с точки
появления (`?level=pocket_meadow&q=high`, окно 720×1280, без интерфейса). Его показывает экран-проём
в жёлтых комнатах: вошёл в экран — оказался на этом лугу. Изменился луг — кадр надо переснять (последний раз — 19.11,
ночью: луг зарос травой плитками до горизонта, design.md, §36). Сам
собой он на экраны не попадает (род `door` в `SCREEN_IMAGES`): его ставит сборка уровня.

## Как добавить картинку

1. Положить полный размер в `master/<id>.webp`, файл для игры (384×640) — в `<id>.webp`.
2. Вписать её в `src/world/screens.ts` (`SCREEN_IMAGES`: id, род, что на картинке).
3. `npm test` (проверяет файлы и размеры) и `npm run build`.

`books.webp` сделана 24 ноября 2026 года (партнёр: «Пусть он продает книги с очень странными обложками, которые нужно сгенерировать
в выбранной нами стилистике»): GPT Image 2 через ElevenLabs, 185 кредитов, принята с первой попытки. Модель выдала лежачий кадр
1280×720 (шесть книг в ряд); в игру пошли два верхних ряда, сложенные по три книги в четыре полки, с тёмными полями по бокам —
исходник в `master/` собран так же и увеличен до 768×1280. Третий ряд с обложкой-лицом в размытии не взят. Надписей, людей и марок нет.
