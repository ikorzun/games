# Криминальная Россия — визуальная новелла-антология с мини-играми

Интерактивная антология по мотивам документального цикла «Криминальная Россия» (НТВ, 1995–2014):
каждый эпизод — одно реальное дело 90-х, рассказанное языком передачи (закадровый рассказчик,
реконструкции, «говорящие головы» следователей, архивные документы), в котором игрок ведёт
следствие, принимает решения и проходит мини-игры, встроенные в сюжетные биты.

Языки: русский (источник), английский (обязательный fallback), испанский, португальский (BR).
Платформы: web/HTML5 (Playgama — основной канал), desktop (Steam/itch) — вторичный.

## Быстрый старт

```bash
pip install jsonschema
python3 tools/validate_episode.py episodes/s1/ep01_murylev.json   # линтер эпизода
python3 tools/loc_sync.py stats episodes/s1/ep01_murylev.json     # прогресс локализации
python3 tools/loc_sync.py export episodes/s1/ep01_murylev.json    # CSV для переводчиков
python3 tools/vnexpr_test.py                                            # самотест грамматики условий
```

## Главные решения (кратко)

1. **Сценарий — данные.** Эпизод описывается JSON по схеме; из него собирается рантайм. Все
   строки — ключи локализации; все имена файлов — латиница.
2. **Нарратив определяет форму.** Архетип дела (серийный убийца, война ОПГ, «квартирные» убийства…)
   задаёт шаблон блоков, визуальный режим каждого блока, набор мини-игр, типы выборов и палитру.
3. **Исторический исход неизменен.** Игрок выбирает маршрут следствия, цену и судьбы вымышленных
   персонажей; реальные приговоры и жертвы не становятся игровыми переменными.
4. **Движок (предложено, ADR-001):** собственный TypeScript-рантайм (PixiJS-сцена + DOM-текст)
   с Playgama Bridge; Ren'Py — эталон UX, но не основной движок (нет адаптера Playgama).
5. **Этика:** уровень фикционализации по умолчанию `dramatized`/`inspired`, изменённые имена частных
   лиц, 18+, без реальных фото жертв. Юридической проверки в процессе нет (решение владельца).
6. **Бренд.** Лицензия на «Криминальную Россию» получена: название, формат и материалы передачи
   используются по условиям договора.
7. **Фирменная механика — реконструкция.** «Замороженная» сцена с заполнением пропусков (The Case of
   the Golden Idol / Return of the Obra Dinn): игрок восстанавливает факты, а не меняет их; рамка —
   «редакция передачи» в настоящем и реконструкция в прошлом.
