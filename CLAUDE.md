# CLAUDE.md — правила работы в этом репозитории

Проект: антология визуальных новелл с мини-играми по мотивам «Криминальной России» (ru/en/es/pt,
web через Playgama + desktop). Карта документов — `README.md`. Сценарий — данные
(`schemas/episode.schema.json`); движок исполняет JSON.

## Команды

```bash
pip install jsonschema
python3 tools/validate_episode.py episodes/<path>.json   # линтер эпизода (должен быть зелёным перед коммитом)
python3 tools/loc_sync.py skeleton|export|import|stats …  # локали
python3 tools/vnexpr_test.py                              # самотест грамматики условий
```

## Конвенции

- Идентификаторы, имена файлов и ключи — только `[a-z0-9_.]`; ключи локализации `ep01.s03.l012`, `ui.*`, `common.*`.
- Текст — только через ключи; `ru` — источник, `en` — обязателен, `es` (нейтральный латиноамериканский), `pt` (бразильский).
- Каждая сцена заканчивается явным переходом; каждая мини-игра пропускаема; ровно одна концовка `canonical`.
- Реальные имена — только у осуждённых по публичным приговорам после `legal_review: done`
  (`docs/production/ethics-and-legal.md`). Преступник неиграбелен в момент насилия.
- Документы: `docs/architecture/02-narrative-blocks.md` — ядро; меняя схему, обновляй линтер и пример `ep01`.

## Делегирование: кто что делает (экономим старшую модель на рутине)

Основная (старшая) модель держит контекст и принимает решения; рутину отдаём субагентам на
младших моделях. Определения агентов — `.claude/agents/*.md` (модель задана во frontmatter).

| Задача | Агент | Модель |
|---|---|---|
| Веб-исследование по списку вопросов, сбор источников, выжимки | `researcher` | sonnet |
| Черновой перевод и редактура en/es/pt по глоссарию и стайлгайду | `translator` | sonnet |
| Черновик сцен JSON по аутлайну и шаблону блоков | `episode-drafter` | sonnet |
| Проверка локалей: длины, плейсхолдеры, пустые строки, статистика | `loc-qa` | haiku |
| Прогон линтера, тривиальные правки (каркас ключей, опечатки id), отчёт | `content-linter` | haiku |
| Механические правки по чёткому ТЗ (переименования, таблицы, списки ассетов, конвертация форматов) | `content-linter` / `loc-qa` | haiku |
| Архитектура, нарративные и визуальные решения, схема данных, юридически чувствительные тексты, финальная проверка перед коммитом | основная модель | — |

Правила:
1. Бриф субагенту содержит: цель, точные файлы, критерий «готово», что НЕ трогать, команду проверки.
2. Результат младшей модели всегда проверяет основная модель до коммита (линтер + выборочное чтение).
3. Младшим моделям не поручаются решения об этике/праве, об изменении схемы и о структуре блоков.
4. Независимые задачи запускаются параллельно в фоне; зависимые — последовательно.
5. Любое изменение контента заканчивается запуском линтера.
