# Картотека задержанных

Кадры для «Межгалактической дежурной части» в выбранном стиле (направление A из `../style/`).
Персонажа задаёт конструктор `src/chargen.js` (набор деталей), рисует генеративная модель: девять
персонажей одним листом 3×3 с одной камерой и одним вестибюлем, лист режется на кадры.

| Файл | Что в нём |
|---|---|
| `batchNN.json` | пакет: девять описаний из деталей конструктора, у каждого свой `id` |
| `batchNN.txt` | промпт листа, собранный из пакета (`node tools/cast_sheet.mjs prompt …`) |
| `batchNN_sheet.webp` | лист целиком, как его вернула модель |
| `cNNMM.webp` | кадры, нарезанные из листа (`python3 tools/cut_grid.py …`), около 650×427 |

Список готовых кадров для страницы и игры — `src/cast.js`; он пересобирается командой
`node tools/cast_sheet.mjs register` и руками не правится.

## Пакет 01 (2026-11-21)

| Что | Значение |
|---|---|
| Сервис, модель | OpenAI API напрямую, `gpt-image-2.6-sunburst`, `quality: high`, 2048×1360 |
| Образцы | `../style/a2_faces.webp` (раскладка кадров, вестибюль, люди) и `../style/cast_galaxy.webp` (существа); в запрос идут их исходные PNG |
| Запрос | один, без повторов и правок; около $0,09 (1 838 токенов изображения на выходе, 2 914 и 1 501 токен текста на входе) |
| Персонажи | водяной, чёрт, серый, головоног, кикимора, робот, Змей Горыныч, человек, слизень |

Палитра задана в самих описаниях: у каждого свой приглушённый цвет кожи и одежды и один яркий акцент
(голубоватый водяной в тельняшке, чёрт в винном спортивном костюме, мятный серый с оранжевым шарфом,
коралловый головоног в сизом плаще, кикимора в сливовом пальто и красном платке, медный робот в
оливковом ватнике, горчичный Горыныч в чернильном пальто, человек в бирюзовом пиджаке, розовый
слизень). Вестибюль и свет те же, что на листах стиля.

Проверка при увеличении (глаза, руки, лишние детали): замечаний к рисунку нет, у всех кистей большой
палец и четыре пальца, у серого только миндалевидные глаза. Модель читает описание свободно и кое-что
добавила сама: шарф серому, платок на шее водяному, жёлтую нашивку на костюме чёрта (акцент; на
эмблему не тянет, но при чистовой съёмке её стоит запретить явно), позы и руки.
