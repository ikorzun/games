# Шрифты

Все четыре гарнитуры распространяются по SIL Open Font License 1.1 (https://openfontlicense.org)
и взяты с Google Fonts в виде подмножеств `cyrillic` и `latin` (woff2).

| Файлы | Гарнитура | Авторы |
|---|---|---|
| `oswald-500-*.woff2` | Oswald | The Oswald Project Authors |
| `ptsans-400-*.woff2`, `ptsans-700-*.woff2` | PT Sans (обычный и жирный) | ParaType |
| `ptmono-400-*.woff2` | PT Mono | ParaType |
| `caveat-500-*.woff2` | Caveat | The Caveat Project Authors |
